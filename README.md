# Ancient Front · Dota 2D

在浏览器中游玩的 Dota 风格 2D MOBA 单人人机原型。目前以 **Dota 2 7.41f** 为数值参照，使用实测地图坐标、三路兵线、28 个野怪营地、完整塔与兵营布局、三维属性及单位装备查看。剑圣、水晶室女、风行者、斧王和昆卡均已接入技能加点、先天能力、天赋和增益/减益状态栏。

## 启动

需要 Node.js 20 或更新版本。在当前文件夹执行：

```powershell
npm run dev
```

打开终端显示的地址，默认是 **http://localhost:5184**。端口占用时自动尝试下一个端口。游戏运行没有第三方依赖，无需先安装包；`npm install` 只用于安装浏览器测试工具。

也可以双击 `启动游戏.cmd`，然后打开窗口中显示的地址。

## Docker / 服务器部署

推送到 `main` 后，GitHub Actions 会验证容器并发布 `ghcr.io/hyn-lei/dota2-2d:latest`（amd64 / arm64）。服务器将 `compose.yaml` 和 `.env.example` 放在同一目录，复制后启动：

```bash
cp .env.example .env
docker compose pull
docker compose up -d --wait --wait-timeout 90
```

默认访问 `http://服务器IP:8080`。首次使用请先等 Actions 发布完成；私有 GHCR 镜像需要登录。完整步骤、镜像权限、更新和回滚见 [部署说明](docs/deployment.md)。

## 英雄

- **剑圣**：Q 剑刃风暴持续伤害、减益免疫与额外魔抗；W 召唤持续治疗且可被摧毁的治疗守卫；E 剑舞为被动暴击；R 无敌斩首击指定敌人，后续跳跃攻击，期间无敌。
- **水晶室女**：Q 冰霜新星减速与减攻速；W 冰封禁制定身、缴械但不沉默；E 奥术光环为被动回蓝；R 极寒领域持续施法并产生随机爆炸。先天能力将魔法消耗转为物理护盾。
- **风行者**：Q 束缚击寻找目标身后的单位或树；W 强力击蓄力并沿飞行路径命中；E 风行加速与闪避；R 集中火力只提高对指定目标的攻击频率，并降低该次攻击伤害。
- **斧王**：Q 狂战士之吼嘲讽并增加护甲；W 战斗饥渴纯粹持续伤害，背向斧王时减速，击杀单位可解除；E 反击螺旋为受击计数触发的被动；R 淘汰之刃造成固定纯粹伤害，击杀英雄重置冷却并获得永久护甲。
- **昆卡**：Q 洪流在施法前摇后延迟 1.6 秒喷发；W 潮汐使者为零魔耗强化攻击和分裂，可按 W 或右键图标切换自动施放；E X 标记对敌方英雄持续 3 秒、友方英雄持续 6 秒，再按 E 免费返回；R 幽灵船实际航行后撞击，路径上的友方英雄获得朗姆酒效果，部分伤害延迟偿还。

每队现包含五位不同的英雄；玩家选择后，队友由另外四位英雄组成。

一级有 **1 个待分配技能点**，四项常规技能均未学习，先天能力自动生效。普通技能四级，分别要求英雄 **1 / 3 / 5 / 7** 级；大招三级，要求 **6 / 12 / 18** 级。英雄升级获得技能点；分配点数后，技能按对应等级增强。鼠标悬停技能可对比当前与下一级数值。天赋在 10 / 15 / 20 / 25 级解锁；全属性最多学习七次。自己与选中单位都可查看实际状态、层数和剩余时间，暂停会冻结计时。

## 对局规则

天辉由玩家和 4 名 AI 组成，夜魇为 5 名 AI。地图为 **20864 × 20864 Source 单位**，横纵比例相同，镜头缩放不改变移动距离。双方共 **22 座塔、12 座兵营、2 遗迹、2 泉水和14座基地建筑**。每一路依次摧毁一塔、二塔、三塔，再攻击兵营。推掉一路三塔后可以攻击基地四塔；两座四塔均被摧毁后才能攻击遗迹。二塔和基地建筑有偷塔保护，需要兵线协助推进。

兵线每 **30 秒** 一波，野怪从 **1:00** 开始每分钟检查营地刷新，刷新范围内有单位时会被封野。野怪有实际编组、属性、奖励、仇恨和回营行为；六处洪流营地逐渐进化。近战/远程兵营被毁后对应兵种升级，全部兵营被毁后出现超级大兵。野区另有肉山和不朽之守护。

初始 **600 金币**，自然收入 **100/分钟**。商店包含 **268 项当前可购物品（含 80 张收费卷轴）**，提供分类、搜索、官方本地图标和组件树；其中 **85 件物品可主动使用**。物品接入治疗、位移、控制、免疫、反弹、吸血、攻击特效、光环、幻象等战斗行为。合成扣除已拥有的组件，支持替代配方、锁定合成、拆分、出售、快捷购买及落地拾取。每件装备保存独立身份、所有者、充能和冷却。

英雄有 **6 格装备、3 格背包、6 格储藏、1 格传送卷轴**；每名英雄拥有独立的六格信使。远程购买普通物品进入储藏处，按 **F3** 让信使回泉水取货并实际飞行或行走送达；可指挥其前往神秘商店购买组件。信使随等级获得飞行、加速、护盾，阵亡后保留货物并等待复活。背包和储藏物品不提供属性，远离商店从背包换入需要六秒；换格保留冷却，换属性保留生命和魔法比例。初始赠送一张传送卷轴，**B** 回泉水消耗卷轴和 75 魔法，并进入冷却；移动、控制或目标建筑消失会中断传送。旅行靴升级卷轴的目标、冷却和消耗规则。

神杖、魔晶已接入五位英雄的技能升级；魔晶在 **16:30** 开始供应，送达装备栏后永久生效。额外技能会出现在技能栏，按 **D** 施放；神杖放进背包后相应升级失效，吞服福佑则永久保留。详见 [升级机制与来源](docs/hero-upgrades-sources.md)。装备按 **1–6** 朝鼠标使用，**Alt + 1–6** 对自己使用；双击装备或在详情中点“使用物品”进入目标选择，右键或 Esc 取消。状态栏与装备格显示实际持续时间、冷却和充能。

力量、敏捷、智力随等级、天赋和装备增长，影响生命、魔法、恢复、护甲、攻速、魔抗等。风行者为全才，每点三维属性提供 0.45 攻击力。普通主属性每点提供 1 攻击力。点击敌方头像可查看三维、战斗属性和当前装备；技能操作与购买作用于自己的英雄。难度调整 AI 反应速度，保持两队基础属性一致。

这是持续开发的二维版本，**尚不是全部 Dota 2 机制的 1:1 实现**。地图实体来源是 7.41 原始导出，底图投影最大校准误差约 66 世界单位；尚未逐格验证客户端碰撞。战争迷雾、反补、完整中立技能/掉落、独立微操与联网仍未完成。治疗守卫和召唤物自动跟随，超距离施法直接拒绝；部分物品弹道、光环叠加和客户端隐藏结算仍有简化。砍树会更新通路并留下树桩，地图底图仍是静态影像。已核实范围和数据冲突见 [完整物品目录](docs/item-catalog-complete.md)、[物品与信使运行时](docs/item-runtime-sources.md)。其他来源：[地图](docs/research/map-sources.md)、[属性](docs/research/attributes-sources.md)、[单位](docs/research/units-sources.md)、[技能](docs/research/abilities-sources.md)、[加点](docs/research/progression-sources.md)。

## 检查与构建

```powershell
npm test
npm run build
```

`dist/` 是静态网站产物，可放到任意静态 HTTP 服务。ES 模块需要通过 HTTP 运行，不要直接双击 `index.html`。

浏览器端验收（先保持本地游戏服务器运行）：

```powershell
npm install
npx playwright install chromium
npm run test:browser
node tests/browser-shop.mjs
```

若服务器使用了其他端口，设置 `GAME_URL` 为实际地址。测试截图保存到 `artifacts/`。测试覆盖技能经济、控制效果、兵线、建筑保护、复活、完整 AI 对局，以及实际 UI 操作、胜负结算、重开和响应式布局。

长时间对局检查可运行 `node scripts/simulate.mjs artifacts/simulation-skills-shop-741f.json`。本轮结果和适用范围见[验收记录](docs/dota-skills-validation.md)及[技能审查](docs/dota-skills-review.md)。早期地图阶段的[模拟记录](docs/dota-741-simulation.md)保留作历史对照。
