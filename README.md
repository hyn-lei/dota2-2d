# Ancient Front · Dota 2D

在浏览器中游玩的 Dota 风格 2D MOBA 原型，支持单人人机和**五真人对五 AI**协作联机。目前以 **Dota 2 7.41f** 为数值参照，使用实测地图坐标、三路兵线、28 个野怪营地、完整塔与兵营布局、三维属性及单位装备查看。剑圣、水晶室女、风行者、斧王、昆卡和食人魔魔法师均已接入技能加点、先天能力、天赋和增益/减益状态栏。

## 启动

需要 Node.js 20 或更新版本。在当前文件夹执行：

```powershell
npm ci
npm run dev
```

打开终端显示的地址，默认是 **http://localhost:5184**。默认端口占用时自动尝试下一个端口；显式设置 `PORT` 或 `--port` 时保留指定端口。浏览器游戏仍使用原生 JavaScript / Canvas；Node 服务新增 `ws` 依赖，同时提供静态页面和同源 WebSocket。首次启动先运行 `npm ci`，双击启动脚本也会在缺少依赖时安装运行时包。

也可以双击 `启动游戏.cmd`，然后打开窗口中显示的地址。

## Docker / 服务器部署

推送到 `main` 后，GitHub Actions 会自动验证、编译并发布镜像（amd64 / arm64）。配置服务器主机和 SSH 私钥后，workflow 的 SSH 步骤会自动创建部署目录、写入 Compose 和首次 `.env`，执行 `docker compose up --pull always` 拉取并启动本次镜像，核对网站版本及公网 WebSocket 握手，失败时恢复旧配置和服务。首次也无需手工上传 Docker 配置。设置见 [自动部署说明](docs/deployment.md#3-配置一次以后自动更新)。

默认访问 `http://服务器IP:8080`。首次使用请先等 Actions 发布完成；私有 GHCR 镜像需要登录。完整步骤、镜像权限、更新和回滚见 [部署说明](docs/deployment.md)。

## 五真人联机

点击大厅的 **“五真人联机 · 对战噩梦 AI”**，填写名字和英雄后创建房间，将邀请链接或六位房间码发给朋友。五个人分别加入、选择不同英雄并准备，房主才能点击“五人出发”。不足五人就等待，不能用 AI 补位；第六人不能加入，同一活动会话不能占多个席位。

敌方是联机专用噩梦档，基础反应间隔 0.03 秒，比离线挑战的 0.08 秒更快，并增加队伍集火、控制衔接、支援和攻防协调。真人各自控制自己的英雄、技能和装备，战斗结果由服务器统一计算。

对局断线会保留真人席位并暂停等待，120 秒内可重连；刷新后关闭提醒，再点联机入口恢复。超时或有人离开会结束该局，全程不转为 AI。个人菜单只停止本人输入，不暂停其他四人。每次打开或刷新网页都会显示可关闭的开发提醒。说明和实现范围见 [联机说明](docs/multiplayer.md)。

## 英雄

- **剑圣**：Q 剑刃风暴持续伤害、减益免疫与额外魔抗；W 召唤持续治疗且可被摧毁的治疗守卫；E 剑舞为被动暴击；R 无敌斩首击指定敌人，后续跳跃攻击，期间无敌。
- **水晶室女**：Q 冰霜新星减速与减攻速；W 冰封禁制定身、缴械但不沉默；E 奥术光环为被动回蓝；R 极寒领域持续施法并产生随机爆炸。先天能力将魔法消耗转为物理护盾。
- **风行者**：Q 束缚击寻找目标身后的单位或树；W 强力击蓄力并沿飞行路径命中；E 风行加速与闪避；R 集中火力只提高对指定目标的攻击频率，并降低该次攻击伤害。
- **斧王**：Q 狂战士之吼嘲讽并增加护甲；W 战斗饥渴纯粹持续伤害，背向斧王时减速，击杀单位可解除；E 反击螺旋为受击计数触发的被动；R 淘汰之刃造成固定纯粹伤害，击杀英雄重置冷却并获得永久护甲。
- **昆卡**：Q 洪流在施法前摇后延迟 1.6 秒喷发；W 潮汐使者为零魔耗强化攻击和分裂，可按 W 或右键图标切换自动施放；E X 标记对敌方英雄持续 3 秒、友方英雄持续 6 秒，再按 E 免费返回；R 幽灵船实际航行后撞击，路径上的友方英雄获得朗姆酒效果，部分伤害延迟偿还。

可选六位英雄，每队仍为五位不同英雄；玩家选择后，队友从其他英雄中选取四位。

- **食人魔魔法师**：Q 火焰爆轰按 0.6 秒间隔多重命中同一目标；W 引燃发射实际追踪弹并延长已有燃烧；E 嗜血术强化友军与塔，Alt + E 对自己施放，右键图标切换自动施放；R 多重施法为被动，力量提高非零概率阈值。先天傻福使智力恒为零，力量提供魔法和恢复；神杖强化 Q 并给予 D 未精通的火焰爆轰，魔晶给予 T 烈火护盾。官方数值、规则解释及尚缺客户端证据的细节见 [食人魔机制来源](docs/ogre-runtime-sources.md)。

战斗特效按英雄和攻击来源区分：冰女使用冰晶与冰爆，风行者使用弓箭和绿色强力击，剑圣使用旋转弧刃与跳跃斩击，斧王使用战吼冲击与落斧，昆卡使用水柱、浪花和幽灵船航迹，食人魔使用火爆、燃烧弹、嗜血环和反击护盾。双方英雄保留相同的技能材质；天辉塔与夜魇塔分别使用金色能量弹和熔火弹。持续特效跟随实际状态与游戏暂停。视觉参照、验证与二维实现边界见 [战斗特效说明](docs/combat-vfx-sources.md)。

一级有 **1 个待分配技能点**，四项常规技能均未学习，先天能力自动生效。普通技能四级，分别要求英雄 **1 / 3 / 5 / 7** 级；大招三级，要求 **6 / 12 / 18** 级。英雄升级获得技能点；技能和七次全属性共 22 个技能点预算。按 7.40 规则，天赋另用独立天赋点，在 10 / 15 / 20 / 25 / 27 / 28 / 29 / 30 级获得；后四级依次开放各层另一侧。分配点数后，技能按对应等级增强。鼠标悬停技能可对比当前与下一级数值。天赋在 10 / 15 / 20 / 25 级解锁；全属性最多学习七次。自己与选中单位都可查看实际状态、层数和剩余时间，暂停会冻结计时。

## 对局规则

天辉由玩家和 4 名 AI 组成，夜魇为 5 名 AI。地图为 **20864 × 20864 Source 单位**，横纵比例相同，镜头缩放不改变移动距离。双方共 **22 座塔、12 座兵营、2 遗迹、2 泉水和14座基地建筑**。每一路依次摧毁一塔、二塔、三塔，再攻击兵营。推掉一路三塔后可以攻击基地四塔；两座四塔均被摧毁后才能攻击遗迹。二塔和基地建筑有偷塔保护，需要兵线协助推进。

兵线每 **30 秒** 一波，野怪从 **1:00** 开始每分钟检查营地刷新，刷新范围内有单位时会被封野。野怪有实际编组、属性、奖励、仇恨和回营行为；六处洪流营地逐渐进化。近战/远程兵营被毁后对应兵种升级，全部兵营被毁后出现超级大兵。野区另有肉山和不朽之守护。

初始 **600 金币**，自然收入 **100/分钟**。商店包含 **268 项当前可购物品（含 80 张收费卷轴）**，提供分类、搜索、官方本地图标和组件树；其中 **85 件物品可主动使用**。物品接入治疗、位移、控制、免疫、反弹、吸血、攻击特效、光环、幻象等战斗行为。合成扣除已拥有的组件，支持替代配方、锁定合成、拆分、出售、快捷购买及落地拾取。每件装备保存独立身份、所有者、充能和冷却。

英雄有 **6 格装备、3 格背包、6 格储藏、1 格传送卷轴**；每名英雄拥有独立的六格信使。远程购买普通物品进入储藏处，按 **F3** 让信使回泉水取货并实际飞行或行走送达；可指挥其前往神秘商店购买组件。信使随等级获得飞行、加速、护盾，阵亡后保留货物并等待复活。背包和储藏物品不提供属性，远离商店从背包换入需要六秒；换格保留冷却，换属性保留生命和魔法比例。初始赠送一张传送卷轴，**B** 回泉水消耗卷轴和 75 魔法，并进入冷却；移动、控制或目标建筑消失会中断传送。旅行靴升级卷轴的目标、冷却和消耗规则。

神杖、魔晶已接入六位英雄的技能升级；魔晶在 **16:30** 开始供应，送达装备栏后永久生效。额外技能会出现在技能栏，按 **D**（第二项为 **T**）施放；神杖放进背包后相应升级失效，吞服福佑则永久保留。详见 [升级机制与来源](docs/hero-upgrades-sources.md)。装备按 **1–6** 朝鼠标使用，**Alt + 1–6** 对自己使用；双击装备或在详情中点“使用物品”进入目标选择，右键或 Esc 取消。状态栏与装备格显示实际持续时间、冷却和充能。

力量、敏捷、智力随等级、天赋和装备增长，影响生命、魔法、恢复、护甲、攻速、魔抗等。风行者为全才，每点三维属性提供 0.45 攻击力。普通主属性每点提供 1 攻击力。食人魔智力恒为零，基础傻福每点力量提供 6 魔法和 0.02 魔法恢复／秒。点击敌方头像可查看三维、战斗属性和当前装备；技能操作与购买作用于自己的英雄。AI 难度影响决策频率和判断，保持两队基础属性、金币收入与技能规则一致。食人魔锁定攻击反复取消前摇的问题已修复；一级正常攻击间隔约 1.49 秒，嗜血与装备按实际攻速缩短间隔。

三档 AI 均会按英雄持续出装、买组件、用信使取神秘商店装备、合成和替换过渡装，并使用主动物品、技能连招、补刀、拉扯、撤退、集火与兵线攻防。敌方休闲 / 标准 / 挑战的思考间隔约为 **0.35 / 0.18 / 0.08 秒**（另有少量随机反应延迟）；队友使用标准策略。传送卷轴、背包和储藏数量不会让购物计划停在五件装备。实现与验收边界见 [AI 行为与出装说明](docs/bot-ai.md)。

这是持续开发的二维版本，**尚不是全部 Dota 2 机制的 1:1 实现**。地图实体来源是 7.41 原始导出，底图投影最大校准误差约 66 世界单位；尚未逐格验证客户端碰撞。战争迷雾、反补、完整中立技能/掉落、独立微操与联网仍未完成。治疗守卫和召唤物自动跟随，超距离施法直接拒绝；部分物品弹道、光环叠加和客户端隐藏结算仍有简化。砍树会更新通路并留下树桩，地图底图仍是静态影像。已核实范围和数据冲突见 [完整物品目录](docs/item-catalog-complete.md)、[物品与信使运行时](docs/item-runtime-sources.md)。其他来源：[地图](docs/research/map-sources.md)、[属性](docs/research/attributes-sources.md)、[单位](docs/research/units-sources.md)、[技能](docs/research/abilities-sources.md)、[加点](docs/research/progression-sources.md)。

## 素材说明

非官方同人学习原型，与 Valve 无关联。Dota 2、英雄名称、英雄立绘、头像和游戏地图素材属于 Valve。英雄图片来自 Steam CDN；地图图片来自 gem-dota 收录的 Liquipedia 7.41 地图，原图未编辑，来源和许可说明见上述地图文档。所有资源保存在本地，运行时不访问外部图片地址。二维移动单位与技能特效由 Canvas 绘制。
