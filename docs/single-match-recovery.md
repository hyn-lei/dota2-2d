# 单机对局自动存档与恢复

误关浏览器标签页后，重新打开同一站点，关闭温馨提示，在大厅点击“继续上次对局”。恢复后先暂停，点击“继续战斗”开始。

进行中的单机对局每两秒保存一次；开始对局、暂停、返回大厅、pagehide 和 beforeunload 也保存。正常关闭与刷新会请求浏览器展示离开提醒，浏览器决定是否显示以及提醒文字。强制结束浏览器或系统回收可能跳过关页事件，此时恢复最近一次定时存档，通常最多回退约两秒。

保存内容包括英雄和 AI、金钱/经验/装备与元数据、技能和状态、待结算技能与多重、兵线/野怪/肉山时钟、毁塔和树木变化、随机种子。真实实体引用按 ID 重绑，空间索引、导航和查询缓存重建。玩家键盘输入清零，恢复时不会自动向前移动。

返回大厅保留对局；开始新局需确认替换，取消时不删除旧存档；正常胜负结算后清除本局继续记录。存储失败会在时间下方显示“存档失败”并提示，原记录保留。损坏或格式不兼容的记录显示错误并保留原字节，只有明确确认开始新局后才尝试替换。

存档键为 `af-single-match-v1`，格式版本 1，当前规则版本 7.41f。状态保存接口位于 `src/game-save.js`，与面向联机浏览器的裁剪快照独立。未来不兼容状态变更必须升级格式或提供迁移，不能把缺失字段填成一局新的默认状态。

范围是同一浏览器配置、同一源站的一局单机游戏，不是云存档或多标签并行对局管理。清除站点数据、无痕窗口结束、存储禁用或空间不足会影响保存。联机房间继续由服务器负责，本地单机存档不能恢复联机对局。更新前从未保存的历史进度无法补造。

验证：`npm test`、`npm run test:recovery`、适用游戏与联机浏览器检查，以及构建/静态检查。恢复浏览器检查已接入 Actions。
