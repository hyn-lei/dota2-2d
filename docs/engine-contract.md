# Shared engine contract

`src/data.js` exports WORLD {width,height}, LANES (array of three arrays of {x,y}, Radiant to Dire), BASES (two {x,y}), HEROES (object keyed juggernaut/crystal_maiden/windranger/axe/kunkka), ITEMS (array), TEAM_COLORS. Axe's extension is specified in `docs/axe-plan.md`; its buffs are `callUntil`, `tauntUntil`, `tauntSourceId`, `hungerUntil`, `hungerDamage`, `hungerSourceId`, and `helixUntil`. Kunkka's extension is specified in `docs/kunkka-plan.md`: `pendingSpells` stores simulation-time impact events; hero `xMark` holds a target id, original x/y and expiry; `tideUntil` primes a single cleaving attack. E recasts while a mark is active are allowed during cooldown and cost no mana. Each team now fields five distinct heroes.

Engine export: `class Game` constructor({hero='juggernaut',difficulty='normal', seed=42}={}). Methods `step(dt)` (dt seconds), `moveTo(x,y)`, `setMovement(x,y)` normalized input for WASD (0,0 stops keyboard movement, but preserves clicked destination), `attackTarget(id)`, `cast(index,targetPoint)` returns {ok,reason?}, `buy(itemId)` returns {ok,reason?}, `recall()` returns {ok,reason?}, `setPaused(bool)`. `damage(target,amount,source)` is public for simulation tests; `isProtected(entity)` determines building invulnerability. `get player()`.

Game public state: `time`, `status` ('playing','won','lost'), `paused`, `winner` (null,0,1), `score` [radiantKills,direKills], `entities`, `effects`, `feed` (newest first, max 5 objects {text,team,time}), `wave` integer. Entity ids unique strings. Team 0 Radiant and 1 Dire. `player` is a hero in `entities`.

Every entity: `{id,kind:'hero'|'creep'|'tower'|'ancient',team,x,y,hp,maxHp,radius,damage,range,speed,attackCooldown,dead:boolean}`. Hero extra: `{heroId,name,isPlayer,level,xp,xpNext,mana,maxMana,gold,inventory:[] (item id strings),kills,deaths,assists,lastHits,cooldowns:[0,0,0,0],respawnTimer,recallTimer,buffs:{},lane,angle}`. Tower extra `lane` (0..2), `tier` (1 outer, 2 inner). Creep extra `lane`, `ranged`. Visual-facing fields can include `attackFlash`, `targetId`, `moving`, `angle`. Keep cooldown and respawn fields nonnegative.

Hero data shape: `{id,name,en,role,description,color,portrait,render,hp,mana,damage,range,speed,armor,skills:[{key,name,description,cooldown,mana,icon,color}]}`. All 4 skills immediately available, automatic stat growth on levels. Buff expiry stored as game-time numbers e.g. `spinUntil`, `hasteUntil`, `shieldUntil`, `ultUntil`, `stunUntil`.

Effect shape `{id,type,x,y,tx?,ty?,radius?,color?,life,maxLife,text?,team?}`. Types 'ring','slash','projectile','heal','burst','text','beam','recall'. Engine updates life and removes expired effects. Renderer can tolerate unknown types. Projectile damage can resolve immediately with cosmetic traveling effects.

Cast uses cursor world position when supplied; otherwise player forward target. Melee Q spin damages nearby enemies over time; W heal; E dash toward target with burst; R multi-hit area slash. Mage Q targeted ice burst+slow; W area freeze; E mana restoration+shield; R channeled-looking blizzard area over time. Archer Q line powershot; W haste+shield; E forward dodge dash; R attack-speed burst. Enforce mana/cooldown/death/paused, meaningful failure reason in Chinese. A reasonable range clamp is allowed. Explicit move/attack/spell cancels recall; incoming damage cancels recall. Recall channels 3 seconds then returns to fountain.

World bases {x:230,y:1570}, {x:2170,y:230}. Player begins near Radiant fountain; no simulation before pressing play. Units can traverse decorative terrain; no tree collision or fog. Aim for ~8-12 minute games, but bot-only simulations should eventually end. Spawn 3 melee+1 ranged per lane per team every 18 sec. Bots rotate only as needed, attack nearby enemies, retreat when low, and use spells. Fountain regenerates allied heroes and hurts enemies. Buy anywhere (courier simplification), six slots, permanent stat upgrades applied immediately; repeat items allowed. Passive income +4 gold/sec, starting gold 650. Death respawns in 8+level seconds, retains equipment. 5v5: player +4 allied bots and5 enemy bots.
