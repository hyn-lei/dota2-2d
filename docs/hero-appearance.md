# 英雄局内外观

十名可选英雄均使用仓库已有的透明高清角色图，提供与编织者相同的局内角色绘制方式。角色保持直立，随朝向左右翻转；原有移动起伏、隐身透明度、物品光效、技能特效和幻象蓝色染色保留。

`scripts/generate-hero-sprites.py` 将原图按透明边界裁切，并生成 `assets/hero-sprites.png` 与 `src/hero-sprite-data.js`。图集为 1920 × 768，总解码像素约 147 万，避免局内分别解码十张 1440 × 1440 原图。浏览器共享一份图集；加载期间沿用已有绘制，构建和运行无需 Python。重新生成素材时需要 Pillow。

浏览器检查 `tests/browser-hero-appearance.mjs` 覆盖全部十名英雄的实际绘制、幻象颜色和渲染耗时，并保存局内截图。这里采用二维角色素材绘制，没有增加 Dota 2 客户端的三维骨骼或完整攻击动画。
