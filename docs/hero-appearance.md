# 英雄局内外观

十名可选英雄均使用仓库已有的透明高清角色图，提供与编织者相同的局内角色绘制方式。角色保持直立，随朝向左右翻转；原有移动起伏、隐身透明度、物品光效、技能特效和幻象蓝色染色保留。

角色图底部与脚下的选中圈使用同一基准，修正编织者原先悬在圈上方的偏移。骑乘的混沌骑士、陈和体型较大的食人魔使用各自的高度，脚下水平位置按底部不透明像素确定；血条随实际模型高度放置。编织者原有图片、尺寸、颜色、脚下基准保持。鼠标检测同时覆盖英雄实际造型和地面圆圈，包含攻击时的身体与武器位移，适用于悬停、左键查看和右键攻击；不改变游戏碰撞或攻击距离。隐身敌人仍须实际可见，空地继续用于移动。

`scripts/generate-hero-sprites.py` 将原图按透明边界裁切，并生成 `assets/hero-sprites.png` 与 `src/hero-sprite-data.js`。图集为 1920 × 768，总解码像素约 147 万，避免局内分别解码十张 1440 × 1440 原图。浏览器共享一份图集；加载期间沿用已有绘制，构建和运行无需 Python。重新生成素材时需要 Pillow。

`src/hero-attack-animation.js` 读取实际攻击前摇和普通攻击释放事件，绘制蓄力、出手与收回。近战前冲、远程后坐、编织者压低身体；斧王、昆卡、混沌骑士、食人魔的外露武器围绕握持点独立挥动。武器从同一图集用缓存的路径裁切，不创建额外大图或每帧解码。握持的手、身体与坐骑留在角色层。编织者的连击可以在下一次主攻击前摇中真实释放，较新的释放事件优先。取消前摇不误播出手，暂停冻结动作，幻象按自己的实体记录攻击。

短程弹道可能在两次联机快照间消失，因此以权威快照时间与释放闪光推断一次出手时间。显示时钟外推或迟到的新快照都不能重播、倒播同一个动作；只有换局、权威时间回退或大跳才清除旧记录。

浏览器检查 `tests/browser-hero-appearance.mjs` 覆盖全部十名英雄的实际绘制、幻象颜色和渲染耗时；`tests/browser-hero-attacks.mjs` 覆盖真实攻击、取消、暂停、高攻速连击和迟到快照；`tests/browser-hero-picking.mjs --attacking` 覆盖动作中的实际鼠标指令。截图与本轮证据见 [验证记录](verification/2026-11-22-hero-attacks.md)。这里采用二维角色与武器动作，未导入 Valve 三维骨骼或宣称复刻其全部动画。
