# 键位设置与单位碰撞

## 键位

对局左上角游戏标识旁的齿轮打开设置，大厅齿轮也使用相同设置。点击任意技能或物品键位，然后按一个字母或数字；可分别配置四个技能和六个装备栏位置。保存立即生效，不需要重新开局。设置以 `af-keybindings-v1` 保存在当前浏览器、当前网站，不改动英雄技能或物品的官方 ID，也不改变联机协议中的技能序号和物品槽位。

例如，先把技能改为 **ASDF**，再把物品改为 **QWERTY**，点击“保存并返回”。编辑过程中允许暂时重复；重复或无效键位必须修正后才能保存。技能、装备、附加技能、技能升级和指南的按键提示均随设置更新。Ctrl + 新技能键加点，Alt + 新技能 / 物品键对自己施放。

B / G / H / M / P / U 分别保留回城、快捷购买、指南、全图、暂停和天赋功能，Esc、Tab、方向键、空格和修饰键也不能绑定到技能 / 物品。技能 / 物品优先使用配置的按键；A / S 被绑定后不再同时移动，方向键始终可用；F 被绑定后使用 Tab 打开商店。附加技能优先使用 D / T，占用时按稳定顺序选择空闲键，ASDF + QWERTY 时为 Z / X，实际按键显示在对应图标上。

录入期间不会向游戏发送操作。Esc 取消当前录入，再次 Esc 关闭设置；关闭窗口会放弃未保存的键位。“恢复默认键位”先修改编辑草稿，保存后恢复 QWER / 123456。单机设置窗口暂停模拟，联机窗口沿用原有个人菜单语义，不暂停整个房间。存储失败会明确提示，并保留此前生效的键位。

## 碰撞

`src/collision.js` 在实际模拟中检测地面英雄、兵线、野怪、召唤物、幻象、地面信使和守卫的足底范围；同队和敌队都能形成阻挡。建筑使用现有地图导出的矩形 `bounds`，移动单位使用独立的 `collisionRadius`，不使用官方 `RingRadius` 选择圈作为碰撞半径。攻击范围、选择范围和美术显示保持各自语义。

连续扫掠检测避免一步直接穿透单位；接触后沿边缘滑动，必要时增加局部绕行点，保留原有地形路径。碰撞查询使用 256 世界单位的空间分桶，移动后同步更新索引。死亡单位立即解除阻挡，出生或移动前的重叠可向外分离，已有不可通行出生位置允许沿原寻路结果离开。

有效 `phased` 属性可以穿过单位，延迟生效和结束时间均使用比赛时钟。相位鞋、迅捷闪光和净魂之刃升级的相位增益沿用已有状态；风行、影刃和白银之锋也接入单位通行属性。相位仍受建筑、树木和地形阻挡。飞行信使沿用已有飞行通行规则。传送、跳跃与强制位移仍由对应技能 / 物品处理，不把正常行走碰撞直接套到所有特殊位移。

这是原生 Canvas 工程的二维碰撞实现，不宣称等同 Source 2 的原生碰撞体、推挤优先级或寻路网格。原始数据与边界见 [单位来源](research/units-sources.md) 和 [物品运行时来源](item-runtime-sources.md)。2026-11-08 核对 Valve 官方 `https://www.dota2.com/datafeed/patchnoteslist?language=english`，最新补丁仍为 7.41f；本次不改动伤害、成长和物品数值快照。
