## 官方资料与自定义决策的分界

当前英雄与物品参照 **7.42**。当日加入编织者时已核对 Valve 最新版本，核对记录与官方补丁响应为 [version-check.json](research/weaver/version-check.json)、[patch-schinese.json](research/weaver/patch-schinese.json)，具体数据来源见 [编织者来源说明](weaver-runtime-sources.md)。此次仅改工程 AI 决策，未修改官方快照、生成器、英雄/物品数值或地图。

五档策略是本项目的启发式实现，未接入 Valve 客户端机器人程序。中文“疯狂”用于描述本工程第四档；“炼狱”增加了下述实战决策，相比本工程挑战、疯狂具有更多反制能力。没有与原生 Dota 2 疯狂机器人的同条件对局、胜率或操作质量基准，因此不声明两者强度相同，也不声明第五档客观强于 Valve 机器人。原生客户端与本工程机制的已知差异仍以 [物品运行时来源](item-runtime-sources.md)、各英雄来源说明及 README 为准。

## 各档实际区别

| 档位 | 决策能力 |
| --- | --- |
| 休闲 | 原有较慢反应、较小局部感知范围、宽松战力判断。 |
| 标准 | 原有均衡反应，正常技能、物品、购物和支援流程。 |
| 挑战 | 原有更快反应、近距离远程拉扯、塔下退避与物品使用。 |
| 疯狂 | 共享可见战况并集火；保留后续控制，按前摇、弹道和状态抗性衔接；识别入射控制与可驱散减益，及时使用已拥有的 BKB、分身斧、卫士胫甲或撒旦。 |
| 炼狱 | 继承疯狂；优先以可用且能及时落地的技能/物品打断可见持续施法；识别莲花反射、林肯抵挡与减益免疫；有合适后续控制时先用次要定向技能破抵挡；按观察到的移动预判技能并提前拉开近战追赶距离；无施法威胁时保留 BKB。 |

休闲、标准、挑战原有 `reaction/jitter/awareness/lead/advantage` 数值保持。第四档的决策计时为 30–35 毫秒，第五档为 20–22 毫秒；这只是 AI 决策计时器，不意味着真实游戏每 20 毫秒就能操作。模拟帧率、实际调用间隔、技能前摇、转向、移动与弹道仍限制反应。10 毫秒步长的确定性索敌用例中，挑战在 90 毫秒后取得新目标，炼狱在 30 毫秒内取得目标；不能把此数值直接当作浏览器或服务器端延迟。

两队团队观察/任务分配和集火视图仍共享约 200 毫秒的缓存；配置中的疯狂 0.2 秒、炼狱 0.15 秒 `macroInterval` 用于本地宏观重评估，不保证全图观察刷新到 150 毫秒。普通塔与交战使用人数预算，基地危机保留多人回防；临时任务只保存目标与任务兵线，不永久改写英雄的开局 `h.lane`，任务结束后重新接回原兵线路点。具体分配由 `bot-tactics.js` 负责。

## 使用的真实战斗管线

- 技能由 `hero-runtime.js` 的常规/额外技能入口施放，物品由 `item-runtime.js` 使用；检查实际等级、魔法、距离、前摇、冷却、物品所有权和背包激活时间。十位现有英雄继续保留各自技能逻辑与原出装路线。
- 控制衔接包含已开始的友军前摇、已生效控制及实际弹道；混乱之箭在团队缓存重建后仍会阻止冰封禁制提前重叠。斧王的狂战士之吼按当前运行时穿透减益免疫，火焰爆轰等不穿透技能会保留。
- 反射/抵挡判断只用于当前可见敌人。定向技能在莲花反射期间保留；林肯可由食人魔引燃、混沌骑士实相裂隙或有后续控制物品时的陈赎罪等次要技能先处理。没有合适破抵挡手段时保留关键定向控制，范围技能和普攻仍走原管线。
- 冰封禁制的缠绕不会打断普通持续施法；炼狱用眩晕、嘲讽或沉默反制这类读条，已有冰封禁制或待落地的同类缠绕也不会阻止必需的打断。TP 属于可被缠绕中止的物品引导，可以使用缠绕；AI 不把所有根系控制都当成眩晕。
- 入射威胁来自可见敌人的定向施法前摇、追踪控制弹道、释放后的洪流预警/幽灵船位置及极寒领域。不会用尚未释放的范围技能目标点猜测敌方指令，也不会用不可见敌人的坐标、读条或移动订单作判断。移动预测仅保存当前可见位置的有限差分，离开局部视野后不更新隐蔽轨迹。
- 本工程 BKB 使用会中止当前极寒领域等读条。面对即将到达的控制，AI 可中止读条换取免疫保护；测试按这一实际管线验证，没有悄悄修改物品的引导规则。已禁用 AI、暂停或非战斗状态不会执行该防御。
- 没有难度专属免费装备、生命、伤害、金钱、经验、技能等级或传送。购物继续使用 `bot-items.js`、`inventory.js` 和信使事务；补给、合成、装备替换与 TP 消耗遵守原资金与物品流程。

这些判断并非穷举全部英雄技能、物品或组合，预测也会因突然转向、地形、碰撞与网络帧间隔失误。测试证明指定触发条件下发生了所述行为，不代表固定胜率或全场最优。
