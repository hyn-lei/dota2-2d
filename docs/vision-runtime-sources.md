# 7.42 战争迷雾与可见性

英雄日夜范围沿用 Valve Hero Datafeed。兵线、建筑、侦查守卫、岗哨和虫群从 7.42 单位 KV 读取，虫群甲虫的飞行视野范围为 321。昼夜以对局时间每 300 秒换向，单个单位的实际昼夜属性优先。团队普通视野合并所有存活视野来源，隐形的普通单位需要同队真视才成为可选目标。出处见 [7.42 单位 KV](https://github.com/SteamTracking/GameTracking-Dota2/blob/76ab89451c1384c2e106b676258c6e9f72787e11/game/dota/pak01_dir/scripts/npc/npc_units.txt) 和 [编织者来源记录](weaver-runtime-sources.md)。

普通地面视线按导航格中心检查 7.42 地面高差和树木。低地到高地的遮挡采用 64 单位阈值。静态树覆盖 64 单位半径，临时种树覆盖 48 单位半径。树木遮挡同层及高一层的地面视野。飞行视野绕过树木和地形遮挡。树层在砍伐、种植和到期时重建，每局最多缓存 8,192 条有向地面视线。7.42a 原生中路探针验证由高至低可见、由低至高被挡及全技能虫群穿越高差后增加团队可见性。原版专用树木和悬崖遮挡轮廓、水下边界、泉水入口额外遮挡体及其他技能的临时视野仍待对照。[7.42 地面样本](research/maps/7.42/navigation-sources.md) · [7.42a 可见性样本](verification/2026-11-27-weaver-parity.md#742a-高低差与魔晶补充样本) · [Vision 辅助机制](https://liquipedia.net/dota2/Vision)

侦查守卫提供 1,600 普通视野。岗哨的 1,050 范围是独立检测，放置后另有 150 范围的飞行视野，持续 12 秒。宝石被动检测半径 900。主动宝石的 `Reveal` 在 300 范围对目标施加带真视的 Expose，允许看见被揭示目标，并且周围地块仍按普通视野计算。雾中目标面对其它真视仍保持不可选中。显影状态按来源队伍保存，来源队伍不明的旧状态保持正常地形/隐形判定。见 [Sentry Ward](https://liquipedia.net/dota2/Sentry_Ward)、[Gem of True Sight](https://liquipedia.net/dota2/Gem_of_True_Sight) 和 [Smoke of Deceit](https://liquipedia.net/dota2/Smoke_of_Deceit)。

联机服务按玩家座位所属队伍投影，队友共享同一状态并保留自己的角色 ID。远处敌方英雄仅有公共阵容条目。已观察过的敌方英雄可保留 15 秒最后可见坐标，时限由网页实现选定。服务按可见性筛选实体、效果与弹道端点、动态物资及队伍库存。敌方回溯只发送可见的端点和允许展示的轨迹，回溯预览只对队友可用。界面可以用公开塔和兵营计数以及可见结构的保护状态。敌方隐藏状态未进入客户端实体表，因此不会出现在后续的差分帧和回压补帧。
