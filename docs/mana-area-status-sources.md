# 临时魔法、范围加成与幻象状态补齐

2026-11-08 重新访问 Valve 补丁列表，最新参照仍为 7.41f。物品数值沿用 `docs/research/items/full/` 的官方快照；本次重新查询灵魂之戒（178）、微光披风（254）、风之杖（610）与裂隙之石（1872），查询原文与 URL 保存在 `docs/research/items/rechecks/2026-11-08/`。官方数据、生成器、运行时和本说明分别维护。

- 灵魂之戒：消耗 170 生命，完整给予 170 临时魔法，持续 10 秒。只有溢出部分加入上限；技能、物品和魔法燃烧优先消耗临时魔法，到期只移除未用部分。普通恢复不会重新填充临时池。换装保留普通魔法百分比和临时魔法的独立数值；再次使用替换旧池，死亡清理扩展上限。存档和强幻象各自保存临时池。
- 微光披风：渐隐后给予固定 +20 移速，保留 375 魔法屏障及再次渐隐；不再误算成 +20%。
- 风之杖：只有对自己施放才可按 `tornado_speed=300` 移动。对其他友军或敌军施放时不可移动。官方旧备注仍写 360，与当前数值及主动文案冲突，采用当前数值与主动文案。
- 裂隙之石：官方字段为 `aoe_bonus=40`；补入生成器映射，重新离线生成目录，同时显示“技能范围 +40”。该字段此前存在于快照却没有属性效果。范围物品之间取最大值，再加天赋范围；昆卡 +100 范围天赋不再重复计算。洪流实际边界检查覆盖仅天赋、裂隙之石以及裂隙之石和希瓦同时装备。
- 幻象状态栏：使用本体相同的派生状态查询，显示真实继承的奥术光环、精准光环、射手天赋、物品就绪及永久效果；按来源、破坏、距离和冷却消失。潮汐使者就绪状态随学习、自动施放、冷却和破坏更新。开启臂章只显示一个邪恶之力图标。

`mana-runtime.js` 只记录真实魔法消耗与恢复，不改变原有物品、技能 ID 或网络消息。临时池保存在已有 `statuses` 字段，因此暂停、权威快照和存档沿用同一份状态。旧存档若已在本次修复前消耗过灵魂之戒魔法，未记录的历史消耗无法精确还原；新施放开始使用独立记录。
