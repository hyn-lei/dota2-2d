# 技能点、天赋与属性加点

当前六英雄常规技能的最高等级和学习门槛由官方 Hero Datafeed 与技能脚本生成。普通技能四级，最低英雄等级依次为 **1 / 3 / 5 / 7**；终极技能三级，门槛 **6 / 12 / 18**。

玩家一级有一个未分配技能点，四项常规技能均未学习；先天能力自动生效。每升一级增加一个技能点，可以保留；正常技能与七次全属性共 22 点预算，全部达到后不再增加无用途的技能点。技能强化来自分配技能点，英雄升级本身只提高成长属性及有按英雄等级缩放字段的先天能力。AI 使用相同合法学习接口。

天赋在 **10 / 15 / 20 / 25** 级解锁，一层先选一侧。依据 [Valve 7.29 补丁](https://www.dota2.com/patches/7.29)（本地快照 `progression/patch-7.29.json`），剩余另一侧分别在 **27 / 28 / 29 / 30** 级获得。[Valve 7.40 补丁](https://www.dota2.com/patches/7.40)（本地快照 `units/patch-7.40.json`）进一步把天赋点从技能点分离：10/15/20/25/27/28/29/30 级分别获得一个独立天赋点。天赋消耗天赋点，技能和属性消耗技能点；若之前已选该层一侧，后四级自动用天赋点学习另一侧。若两侧都未选，保留天赋点且开放两侧学习。未提前选天赋的边缘分配顺序尚未经当前客户端回放验证。

属性加点来自 `progression/npc_abilities.txt` 的 `attribute_bonus`：最高七次，初始门槛为二级，随后每两级开放一次，每次力量/敏捷/智力各加二点并消耗一点技能点。经验表沿用已核验的等级一至三十累计规则，见 [属性来源](attributes-sources.md)。

界面支持技能图标上方加号、Ctrl + Q/W/E/R、U 打开天赋与属性面板。技能说明比较当前与下一级数值，并提示英雄等级门槛。`tests/progression.test.mjs` 和 `tests/ogre-parity.test.mjs` 覆盖拒绝非法升级不扣点、保留点数、天赋排他、属性门槛与 AI 到三十级的完整分配。
