# 默认 HUD 与状态显示：来源和实现边界

2026-11-07 核对 [Valve 补丁列表](https://www.dota2.com/datafeed/patchnoteslist?language=english)，最新版本仍为 **7.41f**。原始接口响应保存在 `research/hud/patchnoteslist.json`。英雄、技能、物品数值继续使用项目已有 7.41f 快照，本轮没有改写官方数值记录。

## 界面来源

- [Valve New Journey HUD 介绍](https://www.dota2.com/700/hud)及[官方 HUD 示例图](https://cdn.steamstatic.com/apps/dota2/images/700/hud/carousel_01.jpg)提供默认界面的结构参照：上方两队头像与比分/时钟，左下小地图，中央英雄头像、技能、生命/魔法，右侧六格物品与购买区。该页面为 7.00 历史资料，不能当作当前 7.41f 客户端逐像素截图。
- 技能、先天、升级技能和状态图标由 Valve Steam CDN 获取，原始下载地址及替代情况见 `research/hud/icon-sources.json`；生成器为 `scripts/fetch-status-icons.mjs`。英雄图像继续使用现有本地 Valve 素材。
- 网页 CDN 没有提供 `axe_one_man_army` 和 `juggernaut_bladeform` 的独立图标，分别明确采用狂战士之吼和剑舞图标；记录中的 `fallback: true` 标识这两项替代。通用控制、建筑和位移使用项目 SVG 图标。
- HUD 外框、天赋树按钮、圆形状态边缘和计时环由 CSS/SVG 绘制，不是从客户端导出的 Panorama 材质。`src/dota-ui.css` 在现有样式之后统一调整布局，保留原生 JavaScript/Canvas、英雄/地图/物品 ID 和发布方式。

## 状态数据入口

`src/status-ui.js` 完整读取当前单位的 `statuses`，保留任意已有或新增状态的名称、说明、正负性质、开始/结束时间和层数。状态并不受图标映射白名单限制。已有 `buffs.*Until`、回城和不朽之守护保留兼容入口；显式状态优先，避免过期状态被旧字段重新显示。

之前在战斗计算中生效、却没有 `statuses` 记录的效果由 `src/status-catalog.js` 提供只读显示数据：

| 效果 | 使用的实际状态 |
| --- | --- |
| 奥术光环 | 与魔法恢复共用 `auraManaSources`；已学习的存活友方水晶室女、近距离倍率及自身增强 |
| 精准光环 | 引擎实际授予的 `trueshotAgility`；离开作用范围或源被破坏后按模拟更新移除 |
| 射手天赋 | 与普通攻击共用 `marksmanshipActive`；技能等级、破坏、附近可见敌方英雄及冰川 |
| 治疗守卫、冰川 | 存活守卫/有效区域、阵营、距离、单位类型、实际结束时间 |
| 物品正/负光环 | 物品运行时每 0.25 秒更新属性时附带 `itemAura.displayEffects`；装备所有者、生效时间、禁用、作用范围和阵营 |
| 辉耀灼烧 | 生效的敌方辉耀、开关、作用距离及目标类型；对应实际持续伤害计算 |
| 永久效果 | 吞服神杖、魔晶、月之碎片、斧王淘汰之刃层数 |
| 装备状态 | 林肯法球就绪、臂章开启、静谧之鞋失效 |
| 其他状态 | 泉水恢复、建筑无敌保护、偷塔保护、强制位移、信使加速/护盾 |

这些显示记录不进入伤害/属性结算，不会把光环属性重复加给英雄。装备光环记录随权威快照一起传输；其他显示读取同一份快照的单位和区域数据。死亡时只显示复活状态。

增益在上排，减益在下排。持续状态不显示虚假的无限计时数字，限时效果按模拟秒更新计时环，暂停不消耗时间。层数独立显示；悬停/键盘聚焦的说明节点在 HUD 更新时保留，效果移除时说明同步关闭。隐身渐隐从 `fadeStartedAt` 显示，普通未来状态仍等待 `startedAt`。重复回城/引导图标已去重。

## 不能据此宣称完整 1:1 的范围

用户的目标是原版 1:1。本轮修正布局和当前引擎的状态显示，但没有当前 7.41f 客户端在固定分辨率、HUD 缩放、默认皮肤下的逐像素对照，也没有完整客户端字体、HUD 材质、三维动态头像及全部 modifier 定义。手机布局为可操作的适配布局，原版没有同等手机界面。

原版光环残留时间、隐藏状态、叠加优先级及未实现的技能/物品例外继续受既有运行时边界限制。状态栏覆盖当前引擎已有数据，不代表补齐 Dota 2 全量客户端机制。详见 [README](../README.md)、[物品运行时](item-runtime-sources.md)、[Drow 来源](drow-runtime-sources.md)。

验收见 [2026-11-07 HUD 与状态栏记录](verification/2026-11-07-hud-status.md)。
