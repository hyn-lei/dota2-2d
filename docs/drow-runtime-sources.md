# 卓尔游侠、远程攻击与渐隐：7.41f 来源和实现范围

## 远程攻击和持续特效

防御塔、泉水、远程兵、攻城兵、远程野怪和远程英雄的普通攻击由模拟器持有实际追踪弹。绘制读取同一位置；发射不造成伤害、吸血、减速、命中火花或攻击计数。命中后才结算；目标死亡、无敌、隐身失去可见性、跳刀或分身等躲弹条件取消命中。攻击者死亡后已发射的弹仍可命中。保存/恢复与暂停保留飞行状态。

塔弹速 **750**，泉水 **1400**，远程兵 **900**，攻城兵 **1100**；英雄按各自 KV 的速率飞行。此前塔弹仅以 1200 速率绘图且出手立即扣血的行为已替换。专家阵列和九头蛇之息的附加攻击同样发射真实弹道。

微光披风在初始 **0.5 秒** 内从可见逐渐变淡，随后隐身；攻击/施法后显形，并在剩余增益期间重新渐隐。友军或被真视发现的单位保留可辨认的透明轮廓；敌方不可见时隐藏。斧王战斗饥渴的头顶标记放大 **2.2 倍**，增加持续地面红光，随真实状态、驱散、死亡与暂停变化。

## 美术来源与尚缺对照的边界

Drow 的本地头像来自 [Valve Steam CDN](https://cdn.akamai.steamstatic.com/apps/dota2/images/dota_react/heroes/drow_ranger.png)。高清透明立绘来自 [Valve 官方英雄 WebM](https://cdn.akamai.steamstatic.com/apps/dota2/videos/dota_react/heroes/renders/drow_ranger.webm) 的 0.8 秒帧，通过浏览器 Canvas 导出 1440×1440 PNG；技能图标同样来自 Steam CDN。本轮没有 AI 生成或冒称原版粒子。战斗中模型、冰箭、波面、冰川及渐隐由 Canvas 绘制。

- 多重射击波间隔采用引导时长 / 波数，波内箭间隔至多 0.1 秒；具体客户端帧时序、英雄碰撞优先级及所有穿透例外尚未独立验证。
- 冰川目前以圆形作用区和前方冰障模拟；原版坡面高度、视线遮挡、飞行视野和高低地命中规则需要完整地形与战争迷雾系统，尚未等价实现。
- 已加入 Drow 与食人魔攻击前摇；其他单位尚未完整实现客户端攻击前后摇、转身、攻击记录及全部弹道例外。
- 幻象、光环残留时间、所有减益免疫/驱散组合以及神杖在飞行中转移的客户端细节尚缺逐项对照；多数定向物品仍采用简化弹道规则。
- 原版三维模型、`.vpcf` 粒子、装饰品、声音和完整视野系统不在当前 Canvas 模拟中。不能将上述公开数值覆盖称为原客户端完整 1:1。
