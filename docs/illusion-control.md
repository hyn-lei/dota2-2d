# 幻象造型、归属与手动控制

2026-11-08 再次核对 [Valve 补丁列表](https://www.dota2.com/datafeed/patchnoteslist?language=english)，最后一项为 **7.41f**。官方原始快照、物品生成结果、运行时实现继续分别保存在 `docs/research/items/`、`src/item-records.js`、`src/illusions.js`，没有修改官方数据来配合实现。

## 操作

- 全部七名英雄的幻象复用本体 Canvas 模型、武器和动画，整身染蓝；底部栏沿用英雄的头部肖像，并增加蓝色辨识。
- 左键选中自己制造的幻象，右键移动或攻击；移动键和已配置技能/物品键作用于所选单位。每个幻象有独立指令，未下令时不跟随本体，也不自动寻找敌人。
- 点击“停止”取消移动、攻击和施法。按空格、点击“返回英雄”或左键点击空地恢复本体；幻象死亡或到期时底部栏自动恢复本体。
- 队友和敌方幻象可在共享底部栏查看，不能操控。服务端核对请求玩家、归属、阵营、存活和物品实例；客户端显示限制之外也拒绝伪造指令。
- 当前只支持逐个选择操控，没有框选或编组。支配单位、治疗守卫的既有行为保持。

## 强弱规则

按本次用户要求，弱幻象继承基础属性、技能等级、天赋及物品被动，禁止主动技能、自动施法、主动装备和回城。复制时不继承本体的临时主动状态，关闭臂章主动力量和冰霜之箭/嗜血术自动施法；本体暴击、射手天赋、先天被动、物品暴击、吸血、光环等走现有被动结算。零魔法值不妨碍被动结算。

幻影斧明确生成弱幻象，保留 7.41f 快照的数量、持续时间、近战/远程输出和承伤倍率。辉耀弱幻象仍采用数据中的幻象灼烧伤害，同种光环不重复叠加。

强幻象继承英雄当前等级、属性、技能、天赋、升级、魔法和装备状态，输出/承伤倍率为 1；可独立施法、引导、使用物品，魔法与冷却分开结算。生成接口为 `createIllusions(..., {type:'strong'})`。当前七名英雄/物品只有幻影斧实际生成幻象，未擅自新增强幻象物品或英雄 ID。

两类幻象均保存独立物品实例；本体借来的非自有装备不会因复制而获得归属。复制装备不能出售、拆分、转移或掉落圣剑。幻象击杀/补刀奖励与助攻记录归制造英雄，攻击技能和物品触发仍以幻象为实际来源。旧存档幻象在恢复时补齐被动、装备、归属和手动控制数据。

## 对照边界

本次的“弱幻象继承被动、强幻象可完整施法”是用户明确指定的玩法。Valve 客户端不同幻象来源还存在专门的技能/物品继承例外，本工程未将这些用户规则宣称为原客户端的全部幻象规则。强幻象复用当前二维英雄实现，其能力范围仍受已有英雄运行时边界约束；蓝色 Canvas 造型也不是 Source 2 三维资源。

自动检查包含：七英雄轮廓与蓝色像素、真实幻影斧生成、无指令待机、独立移动/停止、技能和物品被动、强幻象施法与冷却、服务端越权、复制装备/存档以及两个真实浏览器的 WebSocket 控制。证据见 [本次验证记录](verification/2026-11-08-illusions.md)。
