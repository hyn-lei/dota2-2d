# 7.42 导航更新与高清底图保留

旧 7.41 通行数据会阻挡新版中路通道，并允许部分新版山崖直行。本次从 Valve 原始 `maps/dota.gnv` 重建导航：全部 58,965 个可通行格保留，阻挡格为 47,964。维持原来的 327 × 327 数组、64 单位中心和世界坐标；未改导航算法、动态单位碰撞、英雄/物品 ID。

2026-11-24 客户端已更新到 build 26880867、Client/Server 6993，地图包哈希仍与提取时一致。原始快照、核验版本、格式及转换依据见 [导航来源](../research/maps/7.42/navigation-sources.md)。

用户选择保留现有高清实景图，先使用新版导航。`MAP_IMAGE`、JPG 字节和投影与此前提交完全相同，渲染器没有改动。客户端原生简图只留作来源资料。

复核另修正生成器遗漏：夜魇泉水建筑已是 `(17616,3808)`，旧 `BASES` 却仍为 `(17872,3552)`。现在基地中心由当前泉水派生，回城、治疗与基地商店范围同步到实际位置。新增真实恢复/商店回归在旧中心失败、修正后通过。

导航变化使旧测试坐标落入新山崖。陈受控单位、显式多重射击瞄准、风之杖、鱼叉与两个远端移动用例仅迁移到经核实的可通行位置，原行为断言与阈值保持。出生/复活保留可通行、无碰撞和 AI 离泉检查，以实际泉水恢复及商店可访问替代旧距离假设；恢复脉冲在引导状态下测量，隔离英雄先天属性随地点变化的影响。

已通过的定向验证：

- 新中路通道和新山崖的两项导航用例，均先观察旧数据失败再确认新数据通过。
- 六条泉水到兵线路线，以及独立二进制转换与生成值逐格一致。
- `browser-map-742.mjs`：标准编织者真实鼠标指令通过新通道，并将山崖目标重定向到可走地面。
- 全部八项首次失败用例分别按完整名称验证通过，新增基地恢复/商店用例通过。
- 高清底图与此前提交深比较和字节校验通过；其余发布检查及成熟对局性能由最终记录补充。

最终检查：`npm test` 共 954 项，953 通过、0 失败、1 跳过；`browser-terrain.mjs --painting-only` 在保留的原图配置下通过原有像素、缩放、缓存、桌面/移动和解码回退断言。编织者炼狱档推进三分钟后继续实时运行，测得约 48.94 FPS、p95 33.4 ms，回溯最多 60 条、无页面异常。性能采样未与规则检查并跑。

发布构建与静态检查通过：88 个 JS 模块、488 个本地引用，内容版本 `4ca47453f2a9293d765b92d4f8e208933050aa653dc06f5927bee948c8f3e7ef`。只读审查已核对全格转换、原始哈希、基地位置与测试覆盖；代码推送后使用既有 GitHub Actions 完成镜像及服务器发布，并以公网版本实际核对。

离散地形格不是完整连续碰撞或客户端视野实现。高清底图仍为用户选择的 7.41 图像，文档和运行时元数据明确区分图像与导航版本。
