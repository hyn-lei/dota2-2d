# 7.42 更新与混沌骑士卡死修复验证

## 来源和范围

2026-11-21 两次核对 Valve 补丁列表，最新版本均为 7.42。原始补丁及列表保存在 `docs/research/patches/7.42/`。NPC 镜像固定提交 `76ab89451c1384c2e106b676258c6e9f72787e11`；本机客户端为 Steam build 26825343、ClientVersion 6989。

按用户确认，仅新增混沌骑士，现有八英雄同步更新，保持九位可选阵容。当前物品目录为 354 条记录，包含 274 件可购买物品、48 件活跃中立珍品和 19 类附魔。七种新野怪进入实际刷新、施法和劝化流程。逐项规则及来源差异见 `docs/heroes-742-coverage.md`、`docs/item-742-coverage.md` 与 `docs/research/world-7.42-coverage.md`。

## 第 60 秒停帧

新增营地筛选错误地对 `flooded_small` / `flooded_medium` 访问普通 `CAMP_GROUPS[type].filter()`；普通编组字典中没有这两个键，首次 60 秒刷新抛出异常。多个独立模拟和浏览器观察一致复现，未发现幻象数量递归增长。

修复先区分奔流与普通营地：奔流走原进化编组，普通营地才按主场筛选。保留所有 28 个营地及其刷新框。新行为测试验证完整首刷、清空后 120 秒再次刷新及全部单位的有限属性。

浏览器加速模拟至 180 秒后恢复实时渲染，没有页面异常；恢复 1.5 秒内渲染帧数继续增加。最新完整世界模拟在 60 / 120 / 180 秒分别为 204 / 205 / 207 个实体、8 / 3 / 6 个待结算技能，仍为 playing。此证据覆盖三分钟模拟时间，不把加速推进称为三分钟真实时长的帧率测量。

## 行为和界面

- 最终 `npm test`：807 个用例，806 通过、0 失败、1 跳过；跳过项为本机缺少 Docker Compose 的实际配置校验。首轮旧数值和实际缺陷均按失败完整用例名单独处理；初始化随机数及成长恢复变更后再运行最终规则测试。
- 混沌骑士浏览器检查：九位阵容、静态图片、四技能、当前升级说明、真实 R 幻象、先天 D、幻象控制和保存恢复。
- 装备/升级浏览器检查：动力鞋三种官方属性图标与颜色、臂章开启图标和状态、普通神杖转入背包失效、祝福和魔晶永久生效、选择其他英雄后的升级说明、狂石打造与四级候选预览、防御符文、双生之门实际交互。
- 原 HUD 浏览器回归：状态图标、装备布局、源死亡、驱散与过期、选择敌方英雄、商店交互；1920×1080、1366×768 和 390×844 均无页面横向溢出。
- 地图内存定向检查：运行时解码位图约 20.18 MiB，保留此前相机裁剪和分辨率预算。
- 成熟协作性能检查：249 实体、9 AI，注入 300 ms 往返；约 47.47 渲染帧/秒、46.54 次位置更新/秒，首次可见移动约 50.2 ms，最长渲染间隔 53.5 ms，反向校正 0。快照间隔 P95 为 166.3 ms，所有自动性能断言通过。此结果是受控浏览器测量，不保证任意设备恒定 60 FPS。

代码审查发现并补修魔方/刃甲互反、中立元数据幻象归属、上路战旗保护、附魔吸血/物品威力/减益延长、陈生命光环与升级、混沌骑士追击移速、狂热者技能去重与存档成长同步等真实问题；最后只读复核没有确认未修的重要缺陷。

发布构建与静态检查验证入口导入、全部 JS 模块和本地资源引用。本记录与实现同次提交；推送后以该提交对应的 GitHub Actions 核对发布结果，不把镜像发布描述为外部服务器已经更新。

## 明确边界

地图实体、树木、营地 PHYS 刷新框及路径使用 7.42 原始文件；地形图片和导航栅格仍为 7.41，尤其河道、悬崖和高低差不是最新客户端导航的完整重建。用户此前指定的弱幻象关闭臂章主动力量、强幻象完整施法及狂热者自定义成长继续保留。来源快照和行为测试不代表与 Dota 2 客户端完全等价。

Valve 原始快照按字节保留，包括其既有行尾空白；`git diff --check` 检查作者维护的源码、生成器、测试、README 和入口 HTML，未为消除格式提示改写官方原始数据。
