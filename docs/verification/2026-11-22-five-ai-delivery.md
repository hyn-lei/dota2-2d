# 五档 AI、反隐与英雄点击交付验证

本次保留已经提交的飓风卡死修复和十英雄高清外观，完成此前暂停的 AI 整合。单人提供休闲、标准、挑战、疯狂、炼狱五档；补位队友和联机敌方保持既有难度契约。

普通守塔和附近交战共用人数预算，边路保留必要守军，任务结束后回原分路。旧存档缺少稳定分路标记时按职责恢复 AI 路线；新存档的明确换路保留。反隐使用真实金币、库存、信使、物品消耗与背包延迟，按最后可见位置有限搜索，不读取隐身敌人的新坐标。

复核修正了一处施法时序错误：炼狱食人魔获得神杖后不重复计算施法加速。真实传送只剩 0.3 秒时不会误判为可以打断，剩 0.4 秒时仍会实际完成眩晕并中断传送。

编织者模型底部已对齐地面圈。十名英雄的身体均可悬停、左键查看、右键指定攻击；不可见敌人和空地保持原规则。原大视口验证按每次贴图绘制叠加延迟，在高清角色图接入后放大了注入量；现改为每帧只注入一次，保留原画布缩小、移动和清晰度恢复断言。

## 本地发布检查

- `npm test`：934 项，933 通过、0 失败、1 项跳过。证据为最终运行时代码；新增存档与神杖时序故障都先观察失败再单例确认修正。
- `npm run build`、`npm run check:build`：通过，84 个 JS 模块和 470 个本地引用；构建内容版本 `4f47df64bcade51dba46a5aa2d1b482e510dcca05ffab7710ebb3a425712b67e`。
- `tests/browser-ai-difficulty.mjs`：五档真实选择、九名 AI 开局、保存与继续通过。
- `tests/browser-ai-stealth.mjs`：真实微光快捷键触发 AI 显影之尘消耗、显形和重新索敌通过。
- `tests/browser-ai-performance.mjs`：编织者炼狱档推进三分钟后，约 40.96 FPS，p95 帧间隔 33.4 ms，回溯最多 59 条，无页面异常。
- `tests/browser-hero-picking.mjs`：最终构建中十英雄身体悬停、查看、攻击，隐身不可选与空地移动通过。
- `tests/browser-terrain.mjs --large-viewport-only`：原失败用例通过。画布从 7,718,400 像素降到 1,499,998；成熟对局连续移动约 30 FPS，缩小窗口后恢复原生 DPR，无页面异常。

浏览器与性能检查串行执行，性能采样未与全套 CPU 单测同时运行。帧率是本机指定视口的观测值，不等于所有机器、所有对局或 Valve 客户端的性能与难度基准。
