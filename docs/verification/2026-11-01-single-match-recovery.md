# 2026-11-01 单机误关标签页恢复验证

用户确认问题发生于单机对局：关闭浏览器 tab 后进度消失。原代码只存设置和战绩，对局仅在 Game 内存中。

实现两秒定时本地存档，以及开始、暂停、返回大厅和关页保存；大厅提供继续入口，恢复先暂停。开始新局需确认替换；胜负后清除继续记录；存储失败和损坏记录保留原副本并提示。之前未保存的旧进度无法补造。

## 回归与审查

- `npm test` 最终 355 项：354 通过、0 失败、1 项因本机无 Docker 跳过，日志 `artifacts/recovery-node-final.log`。CI 必须执行该真实 Compose 检查。
- `npm run test:recovery`：刷新后同进度恢复、硬关标签页后读取定时存档、返回大厅保留/取消替换、存储失败四组通过。桌面 1366、平板 768、手机 390 均无横向溢出，继续入口和联机入口可操作。
- 完整游戏浏览器 17 项通过；联机 review 回归 3 项通过。
- 10 分钟真实模拟、40 次保存/恢复后继续运行通过，最大 JSON 长度 261856 字符。
- 构建和静态检查通过：39 模块、107 本地引用；actionlint 通过。

独立审查发现实体 JSON 复制导致 AI 攻击野怪副本、必需嵌套战斗字段校验不足，两项均以失败回归复现后修复：实体引用保存为 ID 并重绑到唯一实体；英雄、效果、营地、延时技能按运行结构验证。实际丢弃装备、世界 tick 后保存恢复和拾取保留同一物品 UID；地上物品不套用战斗单位结构。

中长局验证还确认部分非魔法单位的 mana 会被原模拟写成 NaN；存档编码保留该特殊数值，同时仍拒绝英雄的无效关键数值。Infinity、Map、Set、随机种子和实际待结算多重均保留。导航依真实树木和建筑重建，玩家键盘输入清零。

固定大厅网格行高会裁掉增加按钮后的联机入口，浏览器可点击回归先失败，改为按内容确定轨道高度后通过。恢复浏览器检查已接入自动发布 workflow。

此方案是一份同源浏览器单机存档，未提供多标签并行对局或云同步；不会用单机存档恢复服务器联机房间。线上结果以本次提交对应 Actions 和实际网站版本为准。
