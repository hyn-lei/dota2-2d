# 食人魔无法持续攻击修复

单独提交本修复，以便先上传攻击问题，不等待联机功能整批交付。

原锁定目标、嘲讽和部分 AI 追击循环在攻击冷却中调用 `_move`；它在确认实际位移前清空攻击前摇，造成站在射程内仍每帧重新开始。现只在实际移动量大于零时取消前摇，所有无位移返回路径保留攻击。

官方 BAT 1.7、基础攻速 100、攻击点 0.3 未修改。新增 21 个回归覆盖玩家/AI/嘲讽、140/180 距离、普通/嗜血攻速和主动移动、施法、控制取消。

验证针对暂存的独立修复树，导出到 `artifacts/ogre-attack-upload-check`；该目录的 engine blob 为 `43c690701733f2b84b55c7b6bb47381b54f04421`，与暂存版本相同。没有把尚未提交的联机代码算进本修复测试。
