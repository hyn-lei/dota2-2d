## 独立代码审查及回归

独立只读审查发现三项需修复的特效生命周期问题。分别增加回归测试，观察失败后修复，并重跑全套验证：

- 施放当帧扣除视觉寿命，导致束缚击提前消失：改为按事件 startedAt / maxLife 计算剩余时间；箭持续到实际到达。
- 冰晶克隆躲掉束缚击后箭仍追踪：绘制检查对应的待结算技能；已躲掉的箭不再绘制。
- 强驱散后其他施法者的眩晕让旧绳索重现：绳索绑定命中时的具体状态对象，而非任何眩晕；新增 Canvas 像素检查。

同时修复范围光效与模型共用固定剔除距离的问题，以实际光效范围处理屏幕边缘；新增双方剑圣的剑刃风暴、无敌斩、治疗守卫检查。没有遗留的审查阻塞项。

审查保留的实现边界：普通攻击仍立即结算、随后播放视觉弹道；Canvas 手工表达不会与 Valve 真实粒子完全等价。这两项与任务约束和 README 一致，继续明确记录在 [视觉来源](../combat-vfx-sources.md)。
