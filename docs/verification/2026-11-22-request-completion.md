核对找到并补齐的遗漏：悬红外观特征生成器仍固定原九英雄，未包含编织者。生成器现从当前可选英雄属性表读取阵容，并使用已有 Valve 7.42 编织者原始 KV。四条腿、无鼻、蓝色等字段继承基础定义后覆盖；运行时的蓝色共同特征悬赏可以真正列出编织者和水晶室女并加上制造者专属标记。

生成器增加 `--hero-adjectives-only`，只更新英雄特征导出，无需重写物品目录。与攻击提交比较，原九英雄特征、中立池、附魔和打造规则逐项保持。真实蓝色悬赏回归先失败再通过，原有名单/赏金单次领取回归通过；本地采用这两个直接相关用例，完整 `npm test` 及联机/浏览器发布检查由 GitHub 工作流按实际提交执行。

最终 `npm run build`、`npm run check:build` 通过：88 个 JS 模块、488 个本地引用，内容版本 `6c42b3e9f1daff2b4bd1c503f6523e5c215f465a3209ec9a028ddfc8ae583323`。相同构建目录中的真实攻击全场景浏览器检查通过。

官方角色和规则的二维实现不等于 Valve 三维客户端认证。7.42 实体/树/营地已同步，地形底图与导航栅格的既有 7.41 边界仍明确记录在 [世界覆盖](../research/world-7.42-coverage.md)；不把目录齐全或测试通过写成所有客户端行为完全等价。
