# Dota 7.41f 地图、野区、建筑与属性重建

参照用户 2026-10-24 的指令：使用当前正式版本，优先按实际比例复刻地图、野怪、防御塔和兵营，补全三维属性 / 全才与敌人装备查看。

官方 patchnoteslist 已确认最新补丁为 **7.41f**。地图实体来自 7.41 的原始 VConsole 导出，按小版本地图变更核对；数值使用官方 datafeed 和当前游戏 depot 的 NPC 脚本。数据来源、版本和局限留在 `docs/research/`，不把手绘坐标标作精确数据。

## 实现约定

- 地图使用真实 Source 世界单位，X/Y 等比例映射；摄像机缩放不改变移动速度、攻击距离或路径长度。
- 全部 22 座塔、12 座兵营、2 遗迹、2 泉水及 28 个野怪营地使用导出坐标。河道、森林、高地采用同版本地图底图；导航使用提取栅格和树木障碍。
- 每路三层塔、基地两座四塔；兵营按近战/远程分别升级该路敌方兵种。遗迹需要两座四塔被摧毁。保留建筑残骸并让 HUD 反映实际目标。
- 兵线 30 秒一波，野怪从 1 分钟开始，每分钟检查营地阻挡再刷新。野怪为中立阵营，有真实编组、属性、奖励和仇恨/回营行为。
- 英雄基础三维、成长、主属性、生命/魔法及恢复、攻击范围/间隔/攻速、护甲、魔抗、移动与视野数值由统一函数计算。装备修改属性后重新计算；普通模式两队数值一致。
- 左键选择任何单位查看，右键仍只指挥自己的英雄；敌人详情显示属性和六格装备。选中敌人不能通过技能或购物修改敌方单位。
- 保留现有五名英雄及其已完成的操作链；本次不把原型中尚未逐项复刻的英雄技能、AI 或 3D 引擎宣称为完整 Dota 2 客户端复刻。
