# Cooperative protocol v1

Transport: same-origin WebSocket `/ws/coop`. UTF-8 JSON messages. The server owns all state. Never accept an actor ID, state mutation, difficulty, AI substitute, or arbitrary method supplied by a client.

Client messages:

- `{type:'hello', token?:string, snapshotProtocol?:'delta-v1'}`: create random server identity or resume disconnected one. Reply `welcome` with token, clientId, lastCommandId and the accepted snapshotProtocol when requested. Reject a token already active. An omitted protocol retains legacy full snapshots. A new browser retries without the optional field if an older service rejects it with INVALID_HELLO.
- `{type:'create', name:string, heroId:string}`, `{type:'join',code:string,name:string,heroId:string}`.
- `{type:'chooseHero',heroId:string}`, `{type:'ready',ready:boolean}`, `{type:'start'}`, `{type:'leave'}`.
- `{type:'command',id:positiveInteger,action:string,args:array,slotGuards?:[{area,index,uid}]}`. Actor is the session's bound hero. IDs must exceed session.lastCommandId; welcome carries the counter across reconnect. Item mutations verify guard UID equals the current actor slot when a slot is involved; null can guard an empty destination. No command execution in lobby/disconnect pause/end.
- `{type:'ping',sentAt:number}` → `{type:'pong',sentAt:number}`.
- `{type:'snapshotAck',frame:positiveInteger}`: mandatory after decoding and applying a snapshot. Only a matching outstanding frame on the authenticated current socket releases that frame's credit; stale or unrelated frame acknowledgements are ignored. Invalid shapes or numbers are rejected. This acknowledgement does not mutate the game or advance command IDs.

Server messages:

- `{type:'welcome',token,clientId,lastCommandId,snapshotProtocol?:'delta-v1'}`.
- `{type:'room',room:{code,phase,hostId,capacity:5,members:[{clientId,name,heroId,ready,connected,heroEntityId}],reconnectDeadline?:number}}`. Phase lobby/playing/reconnecting/ended.
- `{type:'snapshot',frame,playerId,roomCode,state}`. State includes time,status,paused,winner,score,entities,effects,feed,wave,camps,pendingSpells visual projection,cutTrees as entries,plantedTrees,shopStocks. Radiant human seats contain `isHuman`; optional Radiant fill and the five Dire heroes have AI controllers. Human names and ownership included; tokens never included.
- Negotiated snapshots also include `commandId`, the last command processed for this session. The first snapshot on a socket, in a new room, or for a different owned seat contains full `state`. Later packets replace `state` with `baseFrame` and `delta:{values,remove,entities:[{id,values,remove}],removed,order?}`. Root/entity values replace changed fields, remove lists delete absent fields, removed deletes entity IDs, and optional order preserves the exact entity array order. Unchanged nested values are reused without mutating the baseline. The base is the previous **sent** frame on this socket; reliable ordered WebSocket delivery permits multiple frames in flight. A browser detecting a missing baseline closes and resumes the reserved session to request a fresh full snapshot.
- `{type:'ack',id,result:{ok:boolean,reason?:string,...}}`: actual executed result. Client must await this before displaying purchase/learning success.
- `{type:'error',code,message}`: lobby/session/transport failure.
- `{type:'end',reason}`: aborted/timeout match; UI returns to lobby without writing a normal win/loss record.

Supported command actions: moveTo, setMovement, attackTarget, cast, castExtra, useItem, toggleAutocast, learnAbility, learnTalent, learnAttributes, recall, buy, moveItem, sellItem, collectStash, queueItem, clearQuickbuy, buyQuick, setCombineLock, disassembleItem, dropItem, pickupItem, courierCommand, buyWithCourier. All parameters pass action-specific validation. Points allow only finite x/y and optional direction x/y in world range, not entity objects. Inventory area/index validates against its actual slot count; client cannot access courier cargo via normal inventory mutation.

`useItem` arguments are `[index, point, area]` with a mandatory source slot guard; recall guards tp slot 0. `pickupItem` calls the authoritative `Game.pickupOrApproach(id)` wrapper to approach distant loot rather than writing a client-only pickup target.

Points may include `self:true`; the server resolves this to the authenticated actor, never a client-selected entity ID. Self Bloodlust and Fire Shield disambiguate overlapping allies. Large snapshots negotiate permessage-deflate, with no context takeover, a 1024-byte threshold and bounded compression concurrency.

Negotiated sockets have at most **four** snapshots outstanding; legacy sockets retain one. Each credit is released only after **both** transport send completion and the browser's application ACK, in either order. This bounded pipeline permits the 100ms snapshot cadence across ordinary WAN round trips. When all credits are occupied, broadcasts coalesce intermediate states into one room/member reference; after a credit becomes available, reproject only the latest state, including a terminal result, if the socket still owns the original connected seat and the room has not aborted. Controls, including command ACKs, do not request compression; they still follow already queued frames and have no absolute WAN latency guarantee. Heartbeat disconnects a socket whose oldest unacknowledged snapshot is older than 30 seconds (checked every 15 seconds), entering the usual reserved-seat reconnect pause. Outgoing byte limits and transport-error disconnect remain in force. Raw WebSocket clients must also send snapshotAck; merely receiving TCP/WebSocket bytes does not release the application gate.

Snapshot encoding preserves recursive Infinity/-Infinity through a dedicated numeric tag and restores it client-side. Commands use ordinary JSON plus strict validators; server must not trust numeric tags as command numbers. Exclude navPath/navGoal/skillCache/innateCache/botState/botShop and Map/cache objects except explicit cutTrees entries. Include pendingSpells identifiers/times needed by active projectile visuals, no AI plans or secrets.

Integration interfaces:

- `Game({hero,difficulty,seed,humanHeroes?:[{heroId,name,clientId}]})`: optional roster constructs exactly five Radiant `isPlayer:true,isHuman:true,controller:'human'` heroes from the outset, skips all bot learning/purchasing. Default constructor unchanged.
- `Game.clearMovement(hero)`: clear only affected hero input. `_playerTick` uses each hero's movement input, not a shared keyboard.
- `CoopGame.withActor(entityId,callback)`: synchronous try/finally actor context for reused Game player commands; no await inside. `game.player` resolves current actor or first human. `clearQuickbuy()` and approach-and-pickup action are authoritative wrappers.
- `NetworkGame.applySnapshot(state,{commandId?,rttMs?})` keeps authoritative queries at the newest server state. `renderView()` returns separate poses for Canvas, the minimap and hit testing. Remote poses interpolate a short snapshot history. Owned keyboard/click movement replays unconfirmed intents using the existing movement speed, terrain path and collision code, with an RTT estimate from ping/command ACKs; confirmation removes processed intents and small corrections decay with an 80ms time constant. Prediction is bounded to 250ms after the latest received snapshot, with at most 250ms of estimated one-way transit replay. Rejected commands, control restrictions, life changes, large teleports, pause/end and disconnect reset or stop presentation. No client simulation step, economy, health, inventory, skill result or command success is predicted. Legacy snapshots omit the command counter and use interpolation without local input prediction.
- `createCoopServer({root,host,port,autoTick,reconnectMs,maxRooms,...})` returns service with server/manager/listen/close for tests and production. Root directory serves only index.html/src/assets. `scripts/server.mjs` starts it with source root in dev, static build root in production.

Defaults: 50ms simulation step, 100ms snapshots, 120000ms reconnect grace, max20 rooms, max120 connections, 8192-byte incoming messages, token-session/lobby expiry cleanup, bounded outgoing buffering. Lobby disconnect releases slot; match disconnect reserves slot and pauses entire game. Clear all held movements when pause starts. Guard old socket close events by socket identity, and heartbeat half-open connections. Limit creation/join/command rates. Production factories contain no debug HTTP endpoints.

Snapshot deadlines advance from the prior scheduled deadline rather than the post-simulation send timestamp. Simulation work therefore cannot silently stretch a 100ms cadence to 150ms. A delayed tick sends the current state once and skips expired deadlines; it never queues a catch-up burst.
