# 7.42 可玩英雄改动覆盖

2026-11-21 按 Valve **7.42**（发布时间戳 `1794988800`）核对现有八位英雄并新增混沌骑士，共九位。2026-11-22 按用户要求新增编织者（63），当前阵容为十位；编织者的数据、隐藏机制来源与边界见 [编织者说明](weaver-runtime-sources.md)。全英雄补丁已保存，但其余英雄没有加入可玩阵容。

官方中英文补丁位于 `docs/research/patches/7.42/patchnotes-{schinese,english}.json`。十位英雄的英文 Datafeed、简体中文 Datafeed 和 Valve KV 分别保存在 `docs/research/heroes/{id}.json`、`docs/research/abilities/{id}-schinese.json`、`docs/research/heroes/npc_dota_hero_*.txt`。固定脚本提交为 [`76ab89451c1384c2e106b676258c6e9f72787e11`](https://github.com/SteamTracking/GameTracking-Dota2/tree/76ab89451c1384c2e106b676258c6e9f72787e11/game/dota/pak01_dir/scripts/npc/heroes)，文件与新增资产的 SHA-256 清单见 `docs/research/heroes/sources-7.42.json`。

## 混沌骑士完整可玩路径

- 混乱之箭：0.4 秒前摇，900 弹道速度；随机伤害和随机眩晕**反向关联**，根据同一次 roll 选择范围。抵挡、反射、无敌和弹道躲避在飞行与实际命中时处理。魔晶生成六秒幻象，继承全额英雄伤害、25% 物品威力并攻击命中的敌人。
- 实相裂隙：目标和混沌骑士沿连线位移，聚拢自己控制的幻象，向目标发出攻击指令；降低 4/5/6/7 护甲六秒。缠绕时不能施放，20 级天赋可穿透敌方减益免疫。
- 混沌一击：英雄和幻象均可触发 120% 至 150/190/230/270% 的随机暴击，按实际攻击伤害治疗 30/40/50/60%；天赋增益生效，Break 禁止触发。
- 混沌之军：弱驱散与短暂无敌后生成三个幻象，持续 30 秒；造成 60/80/100% 伤害，承受 350%（天赋可降为 225%）。重新施放替换旧军队。神杖使每次生成混沌骑士幻象有 50% 几率增加一个，并在主动施放时于全地图生成友方英雄幻象，由混沌骑士控制。
- 天劫前进：持续移动每秒积累 5 移速，最高 `20+2×等级`；停止每秒损失 20，攻击清空。存在至少一个主动混沌之军幻象时，D 可以准备最多一秒并开始全地图点目标冲锋；最多达到最大加速移速的两倍，0.5 秒加速。1300 内所有自己控制的幻象集结跟随，跨越地形、破坏树木，并按真实攻击间隔打击 150 范围内敌人。输入方向或点地命令最多每秒转向 25 度，维持原冲锋时间。S/H 或 D 可提前释放准备，冲锋时再次 S/H/D 可取消；根、眩晕、妖术和嘲讽中止本体与跟随幻象。其他技能会取消冲锋，结束保留 0.5 秒余势。
- 选择、编队、技能学习、天赋、购买、AI 装备/技能/冲锋、保存、合作快照均沿用现有九英雄通用路径。原生 JavaScript/Canvas 和部署入口保持不变。

## 来源差异和边界

幻象继续遵守用户此前明确指定的强弱规则（见 [幻象控制](illusion-control.md)）：弱幻象关闭臂章主动力量，强幻象保留完整装备状态。因此混沌之军的弱幻象也不继承开启臂章的额外力量；这是保留的用户自定义玩法，不能描述为 Valve 原生幻象完全等价。7.42 中立装备属性、附魔与物品威力则按当前幻象来源分别继承。

九位中英文官方快照已核对当前 7.42 字段，食人魔为 295 移速、720 生命，以及最新爆轰、引燃与天赋。网站不包含智力额外魔抗、全才攻击力和傻福魔法，因此这些派生量按当前规则额外核验。陈神杖说明把 CD 写作 40，而当前固定 KV 为 `150/130/110 - 40 = 110/90/70`，运行时按 KV 运算；该说明分歧保留原始材料，不使用网页文字覆盖已知的当前规则。

本轮完成这九位的上述 7.42 改动和混沌骑士完整可玩机制，未把所有官方英雄加入游戏。二维地形落点、骑士队形、树木毁坏和视野仍使用工程现有导航与 Canvas 表现；幻象和暴击的隐藏客户端 PRD/动画采样没有完成逐项客户端认证，现有英雄也保留来源文档中已注明的二维边界。陈的 `zealot-growth.js` 是用户此前明确要求的自定义额外成长，继续保留，单独标注，不冒称 Valve 官方机制。目录覆盖、接口数据和行为测试通过都不代表与 Dota 2 客户端完全等价。

新增行为证据在 `tests/chaos-knight.test.mjs`、`tests/chen-742.test.mjs`、`tests/heroes-742.test.mjs`。既有陈、卓尔、斧王、昆卡、食人魔和升级用例保留其真实施法、错误、所有权、暂停及边界覆盖，只更新本次改动影响的旧预期；废弃迅风斩用例已删除。最终集成验证、浏览器检查和上传证据由仓库主任务记录。

集成审查补充了真实边界回归：陈的先天最低生命增长与花岗岩傀儡光环同步更新基础生命和光环加成，升级及离开光环保持当前生命比例，避免减掉过时的光环数值；混沌骑士的攻击指令追击也积累先天移速，闪烁和推推棒的位移不会计入连续自主移动；恐惧会中止准备和冲锋中的本体与随行幻象。这些失败用例修复后分别定向验证，保留原有按键移动/停止及光环存档清理用例。
