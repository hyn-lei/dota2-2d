# 单人人机开发者模式

在当前单人人机对局中点击左上角齿轮，把设置滚到最下方的 **“是否开启开发者模式”**。点击开关，输入六位数字密码 **821027**，再点“开启”或按 Enter。开启时自己的金钱立即设为 **99999**，生命和魔法的额外回复默认关闭。设置齿轮会显示已开启状态。

## 操作

- **目标英雄**：可选自己的英雄、友方 AI 或敌方 AI；列表显示阵营、英雄名、当前等级和阵亡状态。
- **升到指定等级**：输入不低于当前等级的整数，最高 **30 级**。升级使用已有经验成长流程，补齐合法技能点、天赋点和属性；玩家保留手动加点，AI 按已有策略自动加点。
- **升到满级（30）**：把当前目标升到等级上限。重复请求当前等级不额外发点，也不清除当前等级的已有经验。
- **设为 99999**：把当前目标的金钱余额设为 99999。之后的自然收入、购买和死亡结算仍按正常对局运行。
- **生命值回复 / 魔法值回复**：分别控制当前目标的额外回复。开启生命回复后，在实际游戏更新中补满存活英雄的生命；魔法回复补足可正常回复的魔法值，继续保留灵魂之戒等临时魔法池的消耗和到期规则。开关可随时关闭，普通装备、技能和基础回复继续生效。

每个目标的两个回复开关独立。切换目标不会把上一名英雄的开关复制给下一名英雄。阵亡英雄可以升级，但额外回复不提前复活，也不取消复活倒计时。操作即时生效；“保存并返回”仍用于保存键位并返回战场。

## 当前对局的生命周期

关闭开发者模式会停止所有英雄的额外回复；已经应用的等级、加点和金钱不会回退。再次开启需要重新输入密码，回复开关重新默认为关闭。

关闭设置、暂停比赛仍属于当前对局，模式保持开启。返回大厅、重新开始、对局结束或真正离开网页时自动关闭。刷新后恢复存档、从浏览器返回页面或进入下一局，都需要自行再次开启。实际等级、装备和金钱照常保存在单机存档中，密码、授权状态和回复开关不写入存档或浏览器偏好。

仅支持大厅的 **单人人机** 对局。大厅尚未进入对局时不可开启；所有联机房间和随机匹配均不可用，包括一个真人加 AI 补位的联机房间。联机客户端和服务器模拟都拒绝开发者修改，没有新增对应联机命令。

## 实现与范围

`src/developer-mode.js` 保存每个游戏实例的临时开关，并调用已有经验、魔法与模拟接口；`src/developer-mode-ui.js` 和 `src/developer-mode.css` 提供设置面板。英雄、技能、物品 ID 和原生 JavaScript / Canvas 架构保持原有约定。

修改本体等级、金钱和额外回复不会同步到已存在的弱幻象或强幻象，仍遵循[召唤快照规则](illusion-control.md)。开发者操作是用户指定的本工程功能；沿用当前运行时的 30 级上限，没有修改 7.41f 官方数据快照、生成器或伤害/经济基础数值。

规则检查使用 `tests/developer-mode.test.mjs`，实际界面、保存恢复、响应式布局和联机禁用使用 `npm run test:developer-mode`。发布记录见[本轮验证](verification/2026-11-13-developer-mode.md)。
