# 技能运行时审查

审查日期：2026-10-26。审查使用仓库中的 Valve Hero Datafeed 快照及游戏脚本，不根据旧版本技能印象修改数值。

## 已复现并修复

1. **狂战士之吼到期后仍永久嘲讽。** 状态清理删除 `tauntUntil`，却保留 `tauntSourceId`；引擎将不存在的结束时间与当前时间比较，不能识别已过期状态。现在清理状态同时清理来源，斧王死亡也会立即清理受影响单位的嘲讽及状态栏。引擎另对缺失结束时间采用零值。回归覆盖技能到期、恢复移动、施法者死亡后的状态栏。
2. **狂战士之吼能嘲讽无敌单位。** 范围目标集合包含无敌单位，原分支直接写入嘲讽。现在忽略无敌目标，仍对范围内普通敌人正常生效。这里保留减益免疫与无敌的区别：吼仍可作用于剑刃风暴的减益免疫单位。参考 [斧王官方快照](research/abilities/2-schinese.json) 的技能与免疫字段，以及 [主宰官方快照](research/abilities/8-schinese.json) 对无敌斩无敌状态的描述。
3. **普通剑刃风暴错误获得剑舞暴击。** 原实现每次伤害跳数都掷剑舞暴击；一级风暴在强制命中暴击的条件下由总伤害 425 变成 850。现在风暴按自身每秒伤害结算，普通攻击和无敌斩仍可触发剑舞。依据 [当前主宰游戏脚本](research/heroes/npc_dota_hero_juggernaut.txt) 第 451–453 行的 `can_crit = 0`；[官方快照](research/abilities/8-schinese.json) 当前八项天赋没有启用该字段。脚本中的隐藏旧面具技能不属于当前常规英雄技能配置。
4. **无敌斩第一击可以无视点击目标。** 原逻辑先找到点击目标，又立即将其替换成附近随机单位。现在第一击优先命中仍有效的原目标，之后的斩击才随机跳跃。依据 [主宰官方快照](research/abilities/8-schinese.json) 的无敌斩描述：首先跃向目标单位，再斩击其与附近单位。
5. **顺风层数累计了已经失效的效果。** 原状态栏使用历史 `tailwinds.length`，两次间隔超过持续时间的施法仍显示两层；实际速度计算只应用后一层。现在每步清理已过期的顺风实例并同步层数，重叠效果各自到期后层数也正确减少。持续时间与衰减规则见 [风行者官方快照](research/abilities/21-schinese.json)。
6. **集中火力结束后仍能触发击杀冷却返还。** 原实现仅检查遗留的 `focusTargetId`。现在状态结束及死亡时清理目标标记，返还分支还会验证集中火力仍生效。回归同时保留作用期间的正常 16 秒返还，并确认作用结束后不再返还。依据 [风行者官方快照](research/abilities/21-schinese.json) 的集中火力持续时间和击杀减少冷却天赋。

相关实现：`src/hero-runtime.js`、`src/engine.js`。回归文件：`tests/skill-review.test.mjs`。

- 新增的五项回归先运行全部失败，失败分别为过期来源未删除、死亡后状态残留、无敌目标被嘲讽、风暴伤害 850 而非 425、无敌斩原目标未受伤。
- 后续的顺风与集中火力回归也先观察到失败，再实现修复。
