## 当前可用行为（B1.1）

右键生命不高于 50% 的友方兵线小兵发出普通攻击指令；左键继续选中，高血量友军右键继续移动。近战、攻击点和跟踪弹道复用原攻击流程。反补造成正常物理伤害，受护甲、真实属性和既有幻象输出比例影响，不将低血量单位直接删除。

致命一击使英雄所有者的 `denies` 增加一次，不增加 `lastHits`，双方都没有补刀金币。敌方存活真实英雄在本次样本确定的中心距离 1524 以内平分该小兵正常经验的 50%，己方获得零经验。英雄拥有的幻象和受控单位将反补记给所有者；普通兵线和防御塔不会自动攻击己方。敌方正常补刀的金币和全额经验保持原规则。

`deny-runtime.js` 的判定由本地攻击、权威服务器命令和界面查询共用。收益在共享 `Game._kill` 结算；`denies` 与在途攻击结果随实体存档/联机快照传递，旧存档没有计数时从零累加。已释放弹道保留原攻击者阵亡后仍可命中的行为。

## 防御塔反补（B1.2）

右键生命低于 10% 的友方防御塔发出普通攻击指令。前置建筑保护、塔的攻击免疫和防御符文无敌会阻止反补。近战及远程命中按共享攻击结算处理；偷塔保护保留普通减伤，修复上限扣除本次友方反补造成的伤害。

塔被反补时，双方每位英雄各得该级塔正常团队赏金的一半，包含已阵亡的英雄。项目沿用 75 / 100 / 125 / 150 的各级团队赏金，向下取整后为 37 / 50 / 62 / 75。防御塔反补没有末击额外金币，也不增加小兵的补刀和反补计数。常规敌方摧塔的团队金币和末击金币沿用现有结算。

## 兵营反补（B1.2）

右键生命低于 10% 且已解除前置建筑保护的友方近战或远程兵营可发出普通攻击。防御符文无敌期间拒绝指令，已发出的远程攻击仍在命中时重新核对。偷塔保护按现有规则减伤，修复上限扣除友方反补造成的伤害。

反补近战兵营给敌方每位英雄 125 金，远程兵营为 100 金。反补者与队友没有金币，两队都无末击奖金和经验。兵营被反补后，敌方该路对应兵种升级，己方四塔失去该兵营提供的护甲。

## 基地附属建筑反补（B1.2）

已解除前置保护且生命低于 10% 的友方基地附属建筑可以反补。反补不给双方金币或经验，普通敌方末击仍发放建筑赏金。门槛沿用建筑规则，普通末击赏金来自本项目的 Valve 单位快照。原版附属建筑在 10% 边界的攻击与赏金仍待客户端实测。[社区建筑规则](https://dota2.fandom.com/wiki/Buildings) · [单位快照](research/attacks/npc_units.txt)

## 受控单位与封野守卫（B1.2）

友方英雄可反补生命不高于一半的普通召唤或受控生物。双方均无金币或经验，反补也不记作普通末击。冰晶克隆、幻象、信使、首领及无主单位走各自的规则。7.42a 正式对局样本中，昆卡能命中陈劝化后处于 49% 和 50% 血量的人马可汗，51% 的试次未成为攻击目标。该门槛用于工程中已有资格的普通受控生物。[社区反补规则](https://dota2.fandom.com/wiki/Deny) · [原版取样](research/denies/client-7.42a-controlled.tsv)

活着且尚未到期的侦查、岗哨守卫会阻挡所在营地的实际刷新框。队友可以普通攻击移除框内的满血守卫，框外的友方守卫沿用现有资格。守卫在刷新时刻到期时，营地可照常刷新。[Valve 7.29](https://www.dota2.com/patches/7.29)

## 兵线客户端样本（B1.3）

原版 7.42a 专用服务器 build 26936712 对 49%、50%、51% 的兵线兵分别发出反补订单，前两笔造成伤害，第三笔未命中。另以 49% 发出远程攻击，目标在出手后恢复到 52% 仍被命中。经验样本中中心距离 1524 处获得经验，1525 处没有。网页采用这些边界，释放前仍核对血量，弹道两端任一换队都会取消命中。[原始采样](research/denies/client-7.42a.tsv)

同版本本地专用服务器的选人和正式对局阶段均记录到昆卡将友方兵线兵从 490 血打至 441 血，潮汐使者冷却前后均为 0。正式对局中的天辉中路一塔无无敌状态，9% 血量的试次被选中并受到伤害，恰好 10% 和 11% 的试次均未成为攻击目标，与二维的严格低于 10% 相符。斧王在无减益、引燃和末日三种试次中都未成为友军攻击目标，仍缺英雄反补的阳性对照。防御塔赏金还需单独记录两队玩家金钱。[补充采样](research/denies/client-7.42a-hero-and-tidebringer.tsv)

7.42a 正式对局中，装备代达罗斯之殇的昆卡交替攻击双方各 16 次近战兵线兵。友军每次承受 172 伤害。敌军有 4 次承受 387 伤害，与物品的 225% 暴击倍率一致，其余 12 次均为 172。样本覆盖该装备与兵线的反补；英雄自带暴击、必中和额外攻击仍待核验。[暴击取样](research/denies/client-7.42a-daedalus.tsv)

## 待核验与下一步

- **攻击修饰例外**：当前反补不调用敌方攻击技能或物品触发。潮汐使者和代达罗斯之殇有上述兵线样本。其他暴击、必中、额外攻击、吸血、连击、霜箭和法球仍待逐项对照。
- **建筑的客户端边界**仍需采样其他建筑恰好 10% 的生命判定、塔的奇数赏金取整、前摇和弹道中回血、工程右键与客户端强制攻击的输入差异。
- **英雄反补**需要可反补的持续伤害状态及低血量，另有技能自杀等路径。术语表概述击杀收益规则，Valve 7.36 明确注明反补经验归施加可反补减益的英雄；当前十英雄阵容中仍需逐项确认适用状态与击杀归属。[术语表原文](research/denies/glossary-deny-tokens.txt) · [Valve 7.36](https://www.dota2.com/patches/7.36)

直接行为检查见 `tests/deny-runtime.test.mjs`，实际鼠标输入检查见 `tests/browser-denies.mjs`。当前验证包含项目本地、权威联机与上列兵线原版样本，其它边界按待核验项记录。
