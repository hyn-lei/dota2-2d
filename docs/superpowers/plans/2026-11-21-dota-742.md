# Dota 7.42 更新实施计划

> 实施采用 superpowers:dispatching-parallel-agents：独立文件由独立任务负责，集成与最终验证在当前工作区完成。用户已授权开发和上传；不增加设计审批流程。

## 目标与来源

- Valve 补丁列表在 2026-11-21 核对，最新为 7.42，发布时间戳 1794988800。
- 原始中英文补丁保存于 `docs/research/patches/7.42/patchnotes-{schinese,english}.json`。
- Valve 脚本追踪固定提交为 `76ab89451c1384c2e106b676258c6e9f72787e11`。Datafeed 使用 `language=schinese`，界面使用简体中文。
- 保留既有英雄、物品和地图 ID，原生 Canvas、JavaScript、HTTP/WebSocket 部署入口，地图裁剪与自适应分辨率性能修复。
- 英雄范围待用户回答；先完成现有八位的 7.42 改动与新增混沌骑士，并保存全英雄补丁供范围核对。

## 任务 1：物品

- 更新 `docs/research/items` 原始快照、清单与图标，运行现有物品生成器生成 `src/item-data.js` 等产物。
- 在 `src/item-runtime.js`、`src/item-actives.js`、`src/inventory.js` 等物品模块实现新物品、重做和物品威力；英雄默认 100%，幻象默认 20%，同一减益采用最高威力。
- 从官方字段提取价格、配方、属性、主动与被动；删除物品退出商店但保留 ID 兼容。
- 先增加购买/合成、主动效果、幻象击中和免疫边界行为用例，定向运行失败用例后实现。
- 维护 `docs/item-runtime-sources.md` 与独立 7.42 物品覆盖表，明确运行时效果与纯数据项。

## 任务 2：英雄

- 更新现有英雄中英文 Datafeed、KV、属性、技能、先天、天赋和升级生成器。
- 新增 `src/chaos-runtime.js`，实现混乱之箭、实相裂隙、混沌一击、幻象及当前神杖/魔晶/先天；接入 `src/hero-runtime.js`、`src/data.js`、AI 草案与配装。
- 混沌骑士需要可选、可操控、可保存与网络同步，幻象生命周期、伤害继承和治疗按当前官方数据实现。
- 新英雄引擎接入需求交由集成任务统一修改，避免多人同时编辑 `src/engine.js`。
- 使用真实施法、暴击、吸血、升级与幻象行为测试，维护来源和覆盖文档。

## 任务 3：世界与全局

- 更新 `docs/research/units` 与单位生成器，新增狂海鸥、海象、矿工鼠、远古海豹营地，接入主动、被动及陈劝化技能。
- 更新 `src/hero-stats.js` 属性与经验表、经济奖励、被动经验、兵线时间表、分格生命、免疫规则、地图目标与营地行为。
- 在 `src/engine.js`、`src/neutral-runtime.js`、`src/unit-auras.js` 等入口完成实际模拟行为，禁止用仅修改图标冒充实现。
- 定向验证新野怪施法、成长、营地组成、劝化与兵线/奖励时间边界。

## 任务 4：界面与集成

- 在 HUD 增加神杖和魔晶专属按钮与英雄升级详情，未拥有、背包内、普通神杖、祝福、已消耗魔晶状态正确。
- 动力鞋显示力量红、敏捷绿、智力蓝；臂章及新开关装备显示关闭/开启状态、颜色及廉价 Canvas 特效；状态由当前物品实例读取。
- 简体中文字体优先 Windows 微软雅黑/简体宋体，保留既有排版。
- 使用 Playwright 验证点击、悬停、切换选择单位、背包状态和图标实际可见；控制特效数量避免 AI 性能回退。
- 统一版本与覆盖文档，逐条核对补丁条目，不能把仍缺失机制称作完整实现。

- 实施时只运行对应行为测试；单例失败只重试单例。
- 本次涉及游戏规则，集成后按仓库授权运行 `npm test`。
- 界面使用适用 Playwright 检查及成熟 AI 场景性能回归。
- 发布前运行 `npm run build` 和 `npm run check:build`；证据对应实际提交。
- 完成代码审查，提交代码、原始来源和文档，推送 `origin/main`，检查该 SHA 的 GitHub Actions。镜像发布和服务器更新分别报告。
