# 单机误关标签页后的对局恢复

用户确认场景是单机对局被关闭浏览器标签页。当前 main 只保存设置与战绩，Game 内存随页面销毁，旧进度没有可恢复副本。

采用本地自动存档：每两秒保存进行中的单机对局，在暂停、页面隐藏、pagehide 和 beforeunload 时追加保存。大厅显示“继续上次对局”和英雄、时间、等级；恢复先暂停，点击继续后才运行。存档包括全部有效模拟状态、随机种子、装备元数据、技能与状态、待结算技能、兵线/野怪/肉山时钟、树木和建筑。网格、导航和技能查询缓存重建。

仅离开提醒不能应对强制关闭和系统回收，因此不单独采用；服务器存档会让单机依赖联网，本次采用浏览器存储。浏览器离开提醒由浏览器控制，文字和是否展示不可保证。存储成功才报告成功；空间不足或存储禁用时保留旧存档并提示。当前已结束的旧对局无法补造历史进度。

继续对局不消耗或删除存档。返回大厅保留暂停存档。存在未完成存档时开始新对局需确认替换，取消保留旧进度；胜负结算后删除本局存档。损坏或不兼容存档给出提示，不覆盖、伪造或加载为默认新局。存档按版本校验，仅限同一浏览器、同一站点，不作跨设备同步。

保留原生 JavaScript/Canvas、英雄和物品 ID、现有构建与部署方式。必要测试、构建和静态检查通过后提交并推送 main，检查对应 Actions。
