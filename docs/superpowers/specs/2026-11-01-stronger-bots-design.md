# AI 强度与持续出装设计

目标：显著提升休闲、标准、挑战三档 AI 的战斗能力，修复所有英雄共用固定购物清单、总物品计数到六就停购的问题。继续使用原生 JS / Canvas 和现有英雄、地图、物品 ID。

## 采用方案

采用可测试的规则决策和分阶段出装，复用现有技能、物品、经济、寻路与信使 API。简单提高反应频率不能解决停购、技能顺序和站位；额外属性或金币加成会绕过现有对局规则，因此本轮增强决策能力。

## 购物与成长

五英雄使用不同的开局、核心装和后期路线。购买计划按完成目标推进，而非统计卷轴、储藏和背包占用；已有组件、信使货物计入计划，避免重复买。缺钱时先买便宜组件，远程正常装备进入储藏，信使实际送货；神秘商店组件由信使前往购买。送达组件自动合成，主动整理六格装备，按规则出售过渡装，继续购入核心装、神杖、魔晶和永久升级。魔晶供应时间与库存、金币、出售收益、六秒换装和信使死亡继续遵守现有规则。

各英雄路线保留稳定的在建目标，按对方物理/魔法压力、闪避和自身阵亡情况选择部分防御或反制装备。满配后不会无意义重复买同一装备。玩家装备与技能操作仍由玩家控制。

## 战斗与地图决策

所有难度获得完整出装、补刀、技能连招、主动物品、危险撤退、远程拉扯、合理追击、队友集火与兵线推进。敌方休闲/标准/挑战的思考间隔显著缩短，分别约 0.35 / 0.18 / 0.08 秒，保留强度梯度；队友采用标准策略。

AI 优先残血和被控制英雄，处理范围伤害聚集点；不会用单个小兵浪费所有大招。防御塔下判断友方兵线与敌方火力，人数/血量不利时撤向安全位置；适合时回泉恢复并购物。远程英雄在攻击冷却时拉开距离。昆卡衔接标记、洪流与船，冰女先控制再施放领域，斧王使用跳刀、刃甲与战吼，风行者控制后集火，剑圣用治疗守卫保命并选择合适斩击目标。

选择兵线的推进/防守目标，接应附近队友，兵线空档可刷适合的野怪；避免无穷追击与在危险塔下送死。技能、控制、魔法消耗、冷却、碰撞、塔保护和战斗属性不修改。

## 验收

测试旧停购场景、不同英雄路线、组件合成、信使/神秘商店、满装备后升级、正常金币扣除、三档反应梯度、主动装备使用、追击/撤退与技能时序。运行全套 npm test、适用浏览器检查、模拟对局、构建与构建检查。记录观察到的实测结果，不宣称达到 Dota 客户端机器人的完整水平。验证后提交、推送 origin/main 并检查对应 Actions 和镜像发布。
