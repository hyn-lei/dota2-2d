# 食人魔魔法师数据与机制验收设计

用户要求加入新英雄，并强调 1:1。参照版本以 2026-11-01 Valve 最新补丁 7.41f 为准，英雄 ID 84，运行时 ID ogre_magi。继续保留现有原生 JS / Canvas、五对五、地图与物品 ID。

## 验收原则

先按官方数据与游戏脚本逐项落实属性、四技能、先天、天赋、神杖、魔晶和物品联动；提供对应等级、时序、目标、控制、资源和随机边界测试。无法获得客户端证据的隐藏行为必须标为未验证，不因测试通过而声称与 Dota 客户端全部 1:1。用户已确认“数值与机制逐项核对，画面保留二维”。二维模型、弹道和技能效果按对应实际事件绘制；完整数值与机制等价仍需要逐项官方／客户端证据，不把未验证规则解释计为已认证。

## 数据与方案

官方英文/中文 Hero Datafeed、7.41 补丁和同一固定提交的英雄 KV 分别保存。扩展生成器并独立生成新英雄基础数据，保留已有五英雄数值。食人魔机制放在独立 ogre-runtime.js，接入通用施法、伤害、物品、状态、升级与 AI 流程。

采用真实单位目标、状态和定时事件，而不是简单把伤害乘以多重施法倍数。一级技能点与解锁等级按当前版本（旧命石已废弃）。智力始终为零，力量提供魔法/回蓝。多重施法根据技能等级、力量、天赋与破坏状态决定，只有原始施法支付资源；火焰爆轰重复命中同一单位，引燃有飞行和追加持续时间，嗜血与护盾作用于实际友军及塔。

## 必须检查的内容

- 一级基础属性、成长、物品智力归零、力量魔法与先天天赋。
- Q 各级伤害/晕/魔耗/CD/0.45 前摇，额外命中间隔 0.6，神杖 -1 CD/+25 cast speed。
- W 5/6/7/8 秒、20/30/40/50 DPS、25% 减速、两个目标、1000 弹速、重复命中延长。
- E 普通/自身攻速、移速、30 秒、塔目标、自动施放、多重友军选择。
- R 75、0/30/30、0/0/15 基础概率和每 16 力量 +1 百分点，25 级天赋 +10，破坏与单次支付。
- D 未精通火焰爆轰 150+1.5×力量、当前魔法 35%、7 秒 CD，神杖移出失效。
- T 烈火护盾 3 次敌方英雄攻击、85% 减伤、25 秒、160 反击火球、1400 弹速，魔晶与驱散。
- 10/15/20/25 天赋；25 级攻击触发火焰爆轰；可多重的指向性物品及例外。
- 本地图、5v5 草选、技能界面、AI 出装、模型/图像、弹道和效果，原英雄回归与发布检查。

## 未验证要求

概率分布的客户端随机实现、极端物品/反弹/抵挡/幻象组合、施法速度隐藏计算、所有客户端攻击前后摇与三维表现需客户端对照证据。实现与已验证数据分开记录，不将假设标成已确认。
