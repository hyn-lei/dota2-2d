# 状态栏与英雄技能还原

用户已授权直接继续实现，顺序为状态栏、技能学习与成长、再处理商店。延续现有 Canvas / 原生 ES 模块工程，不改用其他框架。

## 本轮行为

- 一级拥有一个待分配技能点；普通技能和终极技能遵守原版学习等级与最高等级。先天能力单独展示，不消耗技能点。
- 普通技能通过技能加点增强，取消旧版随英雄等级统一乘伤害的逻辑。技能名称、主动/被动类型、伤害、消耗、范围、持续时间和冷却从官方数据及游戏脚本提取。
- 修正五名现有英雄的四项标准技能；被动技能由战斗事件触发。引导、施法前摇、控制、治疗守卫、潮汐自动施放和目标限制接入实际战斗。
- 状态栏展示实际生效的增益/减益、层数、剩余时间与说明；自己的 HUD 和选中单位均可查看。暂停不减少持续时间。
- 技能栏提供加点按钮、Ctrl + Q/W/E/R、等级刻度、锁定说明及当前/下一级数值。天赋与属性加点遵守已核实规则，AI 同样合法加点。
- 核心功能验证完毕后，再扩充商店的分类、搜索、物品详情、组件合成和库存管理；不把未实现的原版效果标作已实现。

## 文件与接口

- `ability-data.js`：五英雄四项技能、先天能力、天赋及来源数据，提供 `abilityAt` / `innateAt`。
- `progression.js`：技能点、学习限制、天赋、属性加点及 AI 分配。
- `hero-runtime.js`：施法与持续效果、攻击触发、伤害修正、状态计算。
- `status-ui.js` / `.css`：状态条渲染，不修改对局状态。
- `engine.js`：接入上述模块，保持移动、建筑、野区与回合模拟接口。
- `main.js` / `skills-ui.css`：技能升级、天赋、说明与 HUD。

## 决策记录

- 将“状态栏”解释为战斗增益/减益栏，同时保留生命、魔法、经验和当前三维属性；覆盖最直接影响操作的信息。
- 数值目标仍为官方当前 7.41f；不再保留原型中的迅捷斩基础技能、主动奥术光环、主动反击螺旋或百分比斩杀等错误设计。
- 数据提取、状态组件、加点规则由各自独立文件承载；根任务负责战斗接入及整体验证，避免多人修改同一引擎文件。
