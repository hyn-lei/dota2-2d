## 已接入的陈规则

- 赎罪：施法前摇和追踪弹，命中后纯粹伤害、减速、攻击该目标的攻速加成及陈的射程天赋；取消施法、弹道躲避、技能格挡和反射。
- 神圣劝化：真实生物等级限制、远古魔晶与上帝之手等级门槛、最早单位替换、独立狂热者名额、金币奖励、满魔、召唤时的生命 / 移速 / 伤害与技能等级快照。未学习 W 时不会给开局狂热者加上 W 的一级数值。取消劝化检查最近三秒受伤并减少十二秒冷却。
- 神力恩泽：生命恢复光环、主动护甲和治疗 / 恢复增强，自身施放作用于本体及自己的军队。
- 上帝之手：全图英雄及自己的受控单位瞬间治疗、持续治疗，神杖引导的附近其他友军减益免疫、魔抗与持续治疗增强，以及强驱散 / 完全治疗天赋。
- 狂热者：开局、陈复活及狂热者死亡倒计时后的生成；普通兵线的时间成长；陈等级攻击力和官方天赋快照；独立殉道按钮。殉道前摇 **0.3 秒**、距离 **500**、弹速 **1000**，伤害为 **25 + 当前生命 × 20%**，友军治疗为该数值的 **50%**。
- D 狂热者召回：全图选择自己的单位，选择陈则召回全军；六秒延迟，敌方英雄或其控制单位伤害中止召回；落点避开单位碰撞。
- 受控生物可独立移动、攻击和施放原有技能，使用自己的魔法、前摇与冷却。其他玩家的单位只读。已接入常见范围控制、投石、诱捕、闪电、冲击波、燃烧、寒冰盔甲、治疗、骷髅、飓风及多种被动和光环。受控者击杀计入所属英雄。

## 用户指定的狂热者指令

狂热者的 **600** 自动搜索范围和殉道的 **500** 施法距离分别处理。

| 指令状态 | 行为 |
| --- | --- |
| 尚无定向指令 | 跟随陈，不主动脱离去搜敌 |
| 点选敌人 | 优先追击这个敌人，不受 600 距离限制 |
| 指定敌人死亡 | 从狂热者自身位置搜索 600 内可见、可攻击敌人；锁定后持续追击；无目标时回陈身边 |
| 点空地 / 停止 | 移动到该处并待命，取消自动索敌 |
| 待命后再次点敌人 | 重新执行指定攻击及击杀后的自动索敌 |

旧 `item-runtime.js` 的召唤物移动会把单位拉回主人周围，导致远距离命令与待命失效；现在统一使用 `controlled-units.js`。键盘的零输入刷新不会更改狂热者的指令模式。指令、所有权、成长和存档状态同时适用于单机及服务器权威联机。

底部提供单个单位按钮，**F1** 选择英雄、**F2** 选择英雄与全军、**F4** 选择英雄以外的受控单位。编队移动、攻击和停止作用于全部选中单位，技能由当前主要单位施放。

## 用户指定的“成长”与限制

这是用户在本轮明确要求的自定义被动，自动显示在狂热者技能框，名称为 **成长**。陈每次从上一等级升到 L 级，额外累加：攻击伤害 **L**、护甲 **0.5L**、魔抗 **L 个百分点**、攻速 **5L**。加成从升到二级开始，满一级时没有升级事件。

| 成长加成 | 限制 |
| --- | --- |
| 攻击伤害 | 无单独上限 |
| 攻速 | 最多 +400 |
| 护甲 | 最多 +50 |
| 魔抗 | 最多 +60 个百分点（60%） |

三次升级到四级累计的等级和为 2 + 3 + 4 = 9，得到 +9 攻击伤害、+4.5 护甲、+9% 魔抗、+45 攻速。到当前最高三十级，累计攻击伤害 +464，另外三项停在各自上限；普通一级狂热者基础护甲 2、攻速 100、魔抗 0，因而仅包含满成长时实际为 **52 护甲、500 攻速、60% 魔抗**。其他有效状态继续参与战斗属性计算。

成长会跟随多级经验升级立即更新；单位死亡期间陈继续升级，新狂热者继承当前等级的累计成长。刷新属性、读档和重连不会重复叠加同一级，旧的未限制成长记录会修正为当前限制。技能详情显示累计量和上限，点击当前底部头像或自己的顶部阵容头像可展开实时详细属性；再次点击、关闭按钮、Esc 或点击外部可收起。

## 兵线外观及实现边界

`src/creep-visuals.js` 为天辉 / 夜魇的近战、远程、攻城三类单位分别绘制普通、超级、全破路大兵三档形象，改变盾牌、武器、头盔、法杖和攻城器械轮廓。仍由原来的兵营和全破路规则决定等级，未改变小兵 ID、地图和兵线数值。

公开字段和本工程测试不能证明与 Dota 2 客户端逐帧完全等价。英雄坐骑、兵线和受控生物使用 Canvas 二维绘制，未导入 Source 2 模型、骨骼、碰撞网格和全部粒子。完整视野 / 高地、原生导航、所有中立能力的隐藏时序与叠加次序仍缺客户端逐项对照；现有中立技能运行时也不构成完整的客户端技能虚拟机。狂热者自动跟随 / 指令模式与“成长”遵循本轮用户指定规则。装备和原有世界简化边界继续见 [装备来源](item-runtime-sources.md) 与 [单位来源](research/units-sources.md)。
